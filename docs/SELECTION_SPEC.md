## 1. 厳選の哲学（憲法との整合・確定版）

スライド12憲法「質は優位を作らない／量でゴール担保」の**真意を確定**する。

- **縦強化はOK**：厳選で**時間をかけて強くなる**のは正当な成長として許容
- **「厳選してない＝弱い」はセーフ**：未厳選で弱いのは締め出しではなく、これから強くなる余地（許容状態）
- 憲法「質は優位を作らない」の実装＝**「特定ビルド一強を作らない＝ビルド多様性の維持」**。質そのものの強化は否定しない
- **いろいろなビルドで戦える**ことが絶対条件。一本道の最適解を作らない

→ 厳選は「縦の成長」＋「横のビルド方向付け」。ガードレールは**基礎値（ベース）設定による一強防止**（§2）。

## 2. 厳選の対象とバランスの取り方

| 区分 | 扱い |
|---|---|
| **基礎値（ベース）** | **固定。バランスの主ノブ**。基礎値の設定で「特定ビルド一強」を防ぐ |
| **味付け部分（ランダムステ）** | 厳選対象。ロール範囲内の**値＋ステ種類の組み合わせ**（横多様性の源泉） |
| **品質(0-5)** | 厳選対象。§3で定義 |
| **スレッド（特殊効果）** | 特殊効果系はクラフト・厳選系はトレジャー（UNLOCK準拠） |

- **格差は許容**。ただし基礎値を適切に設定して一強ビルドを潰す
- 振れるのは「味付け」。ベースの強弱は固定なので、厳選の上振れが**戦力の天井を無限に押し上げない**

---

## 3. ItemQuality(0-5) の定義 = 案a（振れ幅の質）

- 品質は**「良いロールの出やすさ／振れ幅の質」**を表す
- **高品質＝頑張った証**：高品質ほど良いステが出る**確率が上がる**（期待値と上限が上がる）
- 純粋な固定倍率レイヤーではなく、ロール抽選の質を底上げする位置づけ
- ARS_SPECの `damage-bonus` 等の品質効果は、本定義（抽選質の底上げ）に沿って解釈・再マッピングする

## 4. 入手経路の棲み分け（3系統）

| 系統 | 性格 | 供給元 |
|---|---|---|
| **クラフト厳選** | **能動**。素材を注ぎ込んで狙う。鍛冶/錬金の品質倍率が効く | 鍛冶/錬金ツリー（UNLOCK） |
| **ドロップ厳選** | **受動**。攻略報酬として振れたものが出る | EliteMobs CustomDrops / ダンジョン（DESIGN） |
| **トレジャーチェスト** | **特殊**。スレッド等の特殊効果系厳選 | ダンジョン宝箱（UNLOCK準拠） |

## 5. リロール（再厳選）と実装要件

- **リロール＝可（案a）**。ただし**追加コンテンツ**として後付け実装（launch必須ではない）
- ゲームバランスの観点から、リロールは**後から導入・調整**できるよう設計しておく
- **実装要件（重要・ADDON連携）**：
  - **品質・パラメータを後から調整できる関数を用意**する
  - そのため、アイテムのステは**「rollSeed ＋ 品質 ＋ 調整可能なパラメータテーブル」から導出**する設計とし、テーブルを変更すれば**既存アイテムにも再計算で反映**できるようにする（ステを不変ベイクしない）
  - これにより、リロール実装前でも**全体の品質/ステ係数をパッチで再バランス**可能

## 6. コレクション要素（確定：DUNGEON §5）

- UNLOCKの「コア類＝コレクション要素」の図鑑的収集→報酬設計は **`DUNGEON_SPEC.md` §5 で確定**
- **図鑑**（コア/スレッド/モブ討伐の収集記録）を埋めると、段階的に**称号・コスメ・恒久QoL**（戦闘力に直結しない範囲）を解放。**縦強化にしない**
- 供給元（コア＝①フィールド/②反復ダンジョン雑魚、スレッド＝宝箱）は DUNGEON §3。具体の達成条件・しきい値・QoL線引きは数値フェーズ

---

## 7. COMBAT §8 との接続

- COMBAT §8「各ステータスのロール範囲（min/max）と品質倍率の接続」は本仕様で**構造解決**：
  - ロール範囲＝味付けステの振れ幅（ベースは固定）
  - 品質＝振れ幅の質（良ロールの出やすさ、§3）
  - 導出は rollSeed＋品質＋調整可能テーブル（§5）
- 具体的な min/max 値・品質別の確率分布は数値フェーズ
