>
> KGI: プレイヤーの戦闘ステ（ビルド）の使い分けがダンジョンで発生し、ビルドを組みたくなること。

関連コード（現状の事実）: `combat/mob-abilities.yml` / `MobAbilityExecutor` /

---

## 1. 問題

敵の攻撃が読みにくく対策しにくいため、回避やビルドの創造性が出ていない。
TF スキル（矢の雨・召喚・ビーム等）も、中身は通常攻撃の倍率違いに見える。
EliteMobs 側の powers は既に豊富なので、TF が足すのは「ステータスに翻訳できる読み」だけ。

## 2. 三層の住み分け

| 層 | 役割 | プレイヤーが読むもの |
|---|---|---|
| **通常攻撃** | 物／魔の適正 | 頭上の `[耐:物]` / `[攻:魔]` など。一度潜入すれば分かる |
| **TFスキル** | 読み・避け・ビルド分岐の本体 | アクションバーの技名＋予告 |
| **EM powers** | ボス固有の見世物・部屋ギミック | そのボスの記憶（リポジトリから触れない） |

スキルの実体は `MobAbilityExecutor#applyHit` で、モブの `attack-power` × `damage-percent` を
通常と同じ物理／魔法パイプラインへ流している。会心・貫通・出血はモブ刻印にあれば乗るが、
ダンジョン overrides にはほぼ書いていない。矢の雨は `damage-percent: 0` で矢の着弾＝スケルトン通常と同じ。

`piercing_beam`（貫通光）は壁で止まる。横避け＋遮蔽の技であり、壁貫通は未実装。
グローバルクールダウン 12 秒なので、撃った瞬間に対策が違うと感じないと間が無駄になる。

通常の `magic-ratio` は現状どおり（物理推奨ダンジョンは敵の攻撃が魔寄り、など）。
スキルが同じ型の直撃だけだと、頭上タグの再確認にしかならない。

## 3. 直撃ソースと状態異常は別枠

ウィザー等は直撃ソースではない。出血・炎・毒と同じ **状態異常（持続）**。
スキル1発の中身は次の積:

```
手法（雨・ビーム・床…）
＋ 直撃ソース（物理 / 魔法 / 貫通 / 会心 / 回避不能）
＋ 状態異常（なし / 出血 / 炎上 / 毒 / ウィザー）
```

雑魚は「直撃の聞き方を変える」か「状態異常を1つ」か一方。ボスだけ両方。

### 3.1 直撃ソース（ヒット1発。8段のどれを主に見るか）

通常は物理か魔法。スキルはここから選ぶ。

| ソース | パイプライン上の意味 | 主に効く防御 |
|---|---|---|
| **物理** | 物理段を全部通す | 物耐・物守備・防御率・軽減・回避 |
| **魔法** | 魔法段を全部通す | 魔耐・魔守備・防御率・軽減・回避 |
| **貫通** | 防御率を削る／無視。**型は物か魔を持つ**（無属性にはしない） | 耐性・守備が主役。防御率ビルドが負ける |
| **確定会心** | 会心段を必ず通す。型は物か魔 | **防具強度** |
| **回避不能** | 回避ロールを飛ばす | 回避が死ぬ。軽減・HPで受ける |

`percent-bonus` や `damage-modifier` の乱高下はソースではない（量とブレ）。
**固定ダメージ（`fixed-damage`）は対プレイヤーに使わない。** 軽減レイヤーが全部死ぬ。

貫通ヒットとウィザーは役割が違う:

- **貫通ヒット**: その1発で、こちらの防御率が効きにくくなる
- **ウィザー**: 付いたあと、防御率でしか減らない持続ダメージ

今日モブに `penetration` / `crit-chance` を書くと **通常まで** 貫通し会心する。
スキル専用の口はまだ無い。

### 3.2 状態異常ソース（持続）

ヒットに 0 か 1 個乗せる。直撃型とは別に軽減が決まる。
新しい `炎耐性` / `毒耐性` は足さない（通常に使えない死にステが増える）。
回避はティックごと判定しない。会心・防具強度も DoT には使わない。
回復（`health-regen`）は4種共通の二次対策（主対策にしない）。

| 状態 | ティックが通す軽減 | 通さない | 解除・二次 | 既存装備との対応 |
|---|---|---|---|---|
| **出血** | **被ダメージ軽減だけ**（現状維持） | 耐性・守備・防御率・回避 | 回復 | 軽装γ・守衛ロール |
| **炎上** | **物耐＋物守備** | 魔耐・防御率・軽減 | 水・火炎耐性ポーション | ネザライト／ダイヤ（物耐だけ） |
| **毒** | **魔耐＋魔守備** | 物耐・防御率・軽減 | 牛乳・回復 | 守護・魔織など魔耐防具 |
| **ウィザー** | **防御率だけ** | 耐性・守備・軽減 | 牛乳・回復 | 軽装β（防御率） |

炎を物理にした理由は、今の防具の偏り（ネザライトは物耐のみ、魔耐は特定シリーズだけ）を
炎／毒ダンジョンの答えにするため。直感（炎＝属性＝魔）を取るなら、炎と毒を丸ごと入れ替える。
入れ替えるならその1回だけ。

バニラの秒1のままでは差が出ない。ティックを TF 規模にして初めて意味がある。
耐性ポーションは通常の物／魔には効くが、出血・毒・ウィザーには効かせない（一枚岩に戻る）。

## 4. 現状のバニラ炎・毒・ウィザー・出血（実装事実）

| | 炎 (`FIRE` / `FIRE_TICK` / `LAVA`) | 毒・ウィザー | 出血（TF） |
|---|---|---|---|
| TF パイプライン | 通らない | `DotDamageListener` → 出血と同じ式 | `BleedService` → `setHealth` |
| TF で効くステ | **なし** | **被ダメージ軽減だけ** | **被ダメージ軽減だけ** |
| 耐性ポーション | バニラどおり効く | TF が切っている | 効かない |
| 防護／火炎耐性エンチャ | バニラのまま | 防護の MAGIC 補正が残る余地 | 無効 |
| 1ティックの規模 | バニラ（誤差） | バニラ（誤差） | 武器の出血ダメージ（帯で大きい） |

被ダメージ軽減は防御ステ（8段の終盤で通常ヒットにも掛かる）。
出血は攻撃側の継続ダメージで、軽減以外の防御は無視する。軽減は出血専用耐性ではない。

## 5. 攻撃手法（矢の雨の仲間）

既存の型はプレイヤーに要求する動詞で11個。足りないのは VFX ではなく、まだ要求していない動詞。

| 型 | 要求する動き | 既存テンプレ | 充実の方向 |
|---|---|---|---|
| `ground_slam` | 離れる | 震脚、足砕き | 円環（内側安全）、遅延2段 |
| `projectile_volley` | 遮蔽 | 火の粉 | 扇を狭くして当たる弾幕 |
| `projectile_rain` | その場を離れる | 矢の雨 | 炎の雨／氷の雨／矢＋出血 |
| `charge` | 直線から外れる | 突進 | 着地に出血／確定会心 |
| `aura` | 立ち位置を変える | 枯死の霧、凍気 | 毒オーラ、炎床 |
| `teleport_strike` | 後ろを取られない | 影渡り | 回避不能の小ダメージ＋出血 |
| `beam` | 横に避ける（壁で切れる） | 貫通光 | 壁貫通は別フラグ |
| `summon` | 範囲処理 | 招集、群れ | 召喚体にも短いスキル |
| `repulse` | 密着を捨てる | 烈風叩き | KB耐性チェック用 |
| `vortex_pull` | 遠距離を捨てる | 深淵の手 | 引き込み後に別状態 |
| `delayed_zone` | 見てから動く | 星降り、地烈 | 十字、3連、偽物予告 |

足す価値がある型（既存と動詞が被らないものだけ）:

| 案 | 要求する動き |
|---|---|
| 壁貫通ビーム | 遮蔽が死ぬ → 横移動だけ |
| 残存床（pool） | 通った跡が残る。引き撃ちが死ぬ |
| 拡大円環 | タイミング回避 |
| 正面扇 | 盾を向ける／横に出る（360度AoEだと盾が死ぬ） |
| 追尾弾 | 柱の裏へ逃げる（ボス専用でよい） |
| 連結（チェイン） | 固まると死ぬ |
| 多段コンボ | 1発目を見て2発目を避ける |
| 掴み（短い回避不能） | 回避ビルドが通用しない |
| 沈黙／マナ削り | 杖をしまう |

足さない: 即着弾ワンショット、画面外即死、スタン連打、固定ダメージ連打。
スタンは敵→プレイヤーも耐性も無いので、まだソースに並べない。
弱体ポーションは TF 攻撃力をほぼ削らないのでソース扱いしない。

手法ファミリーと装:

| 手法 | 得する装 |
|---|---|
| 雨・遅延設置・拡大円・残存床 | 軽装（速度・回避） |
| 確定会心・ノックバック・正面扇 | 重装（防具強度・KB耐性・盾） |
| 召喚・チェイン | 範囲武器・AoEパーク |
| 貫通直撃 | 耐性・守備寄りの防具 |
| 出血 | 被ダメ軽減 |

## 6. ダンジョンコンセプトの切り方

1ダンジョン ＝ **通常1つ + スキル手法1系統 + スキルの直撃補正か状態異常1つ**。

```
通常の型（既にある magic-ratio）
  × スキルが要求する動き（手法）
  × スキルの直撃ソースまたは状態異常（通常とずらす）
```

通常とスキルが同じ物／魔だと、耐性1種で全部終わる。
スキルは通常と直交させる（例: 通常が魔 → スキル炎で物耐が追加で要る）。

既存ダンジョンは `magic-ratio` で物／魔は振ってある。次は手法＋ソースのラベルを1行足す。
雑魚は手法を共有し、ソースはボスだけ変える（個体ごとにソースを変えると学習できない）。
フィールドのバニラ大型（ラヴェジャー突進等）は序盤の教科書として残し、本格分岐はダンジョンから。

ラベル例（中身は未割当）:

| ダンジョン | 既にある通常 | 足すと効くラベル例 |
|---|---|---|
| ハロウィンアリーナ等・物理推奨 | 攻は魔寄り | 会心の儀式 / 炎床 |
| 花火・魔法推奨 | 攻はほぼ物 | 出血の弾幕 / 毒霧 |
| 世界を繋ぐ者 各段階 | 梯子で物↔魔が交互 | 段階ごとにソースも交互 |
| 下水道 | — | 残存毒床＋鈍足 |
| 蒸気工房 | — | 正面蒸気扇＋盾 |
| 闇の大聖堂 | — | 壁貫通光線 |
| 北の極 | — | 凍気床＋ノックバック（崖） |
| 騎士の城 | — | 突進確定会心 |
| 鉱山・採石 | — | 遅延地裂＋召喚 |
| ネザー鐘・荒野 | — | 炎上＋雨 |
| ギルド | 計測用 | コンセプトを付けない |

頭上は今の2行のまま。スキルはアクションバー技名でソースが分かる名前にする
（「矢の雨」ではなく「出血の雨」）。

## 7. KGI — 戦闘ステがダンジョンで問われるか

採取・クラフト系は対象外。戦闘ビルドに効くキーだけ。

| プレイヤー側 | 今ダンジョンで要求されているか | 要求する敵の出し方 |
|---|---|---|
| 物攻 / 魔攻 | ○ 頭上＋ magic-ratio | 維持 |
| 物耐 / 魔耐 | ○ 通常 | スキルは逆側の状態異常で二段目 |
| 物守備 / 魔守備 | △ 通常に埋もれている | **貫通スキル**で防御率を無効化し差を出す |
| 防御率 | ○ 通常 | 貫通では弱い。ウィザーでは主役 |
| 被ダメ軽減 | △ 通常の劣化版 | **出血**で主役 |
| 防具強度 | × | **確定会心スキル** |
| 回避 | △ スキルも回避できる | **回避不能**との対比 |
| 最大体力 | △ バーストでしか見えない | 予告高倍率 |
| 自然回復 | × | 長い DoT 部屋 |
| 移動速度 | △ 軽装セット | 雨・拡大円・残存床 |
| ノックバック耐性 | × | 烈風＋崖／奈落 |
| 盾 | × | 正面扇 |
| 反射 | × | 多段近接雑魚 |
| 貫通（攻撃） | ロール説明のみ | 敵防御率が高い部屋 |
| 会心（攻撃） | 武器差のみ | 敵防具強度の高低 |
| 出血（攻撃） | 武器差のみ | 敵が被ダメ軽減だけの部屋 |
| マナ | 魔法推奨の攻側だけ | 沈黙／マナ削り（後回し可） |
| AoE（攻撃） | × | 召喚・チェイン |

運用パレット（ダンジョンに振る単位）:

- 通常で物／魔を決める（既存）
- スキルは **出血・炎上・毒・ウィザー・確定会心・貫通** から1つ
- 地形がある部屋だけノックバック
- 回避不能はボス限定でよい

## 8. 実装に落とすときの順番（まだ作らない）

エンジンは小さく、中身は yml で増やす。

1. スキル命中にソースを足す（`physical` / `magical` + `pierce` / `guaranteed-crit` / `ignore-dodge`、状態は `bleed` / `fire` / `poison` / `wither`）
2. 炎・毒・ウィザーのティックを TF 規模にし、§3.2 の軽減だけ通す
3. 会心・貫通は **そのスキルだけ**（モブ全体の `crit-chance` / `penetration` は触らない。通常まで漏れると軽装が全域で死ぬ）
4. 手法は残存床・壁貫通・正面扇の3つまで。追尾・チェインはボス専用
5. ダンジョンにラベルを1行書く（通常 / 手法 / 直撃または状態）。そのあと雑魚へテンプレを貼る。396体に個別ソースは書かない
6. バニラ防護／火炎耐性エンチャは、炎を TF 物理レイヤーに載せたあと「炎にだけ薄い追加」程度が無難

やらないこと: 新耐性キーの先出し、スキルの `fixed-damage`、通常攻撃への出血／会心のばらまき、EM powers の再実装、即着弾ワンショット。

マナ削りと回避不能は、上のパレットが現場に出てから足りるか見る。
