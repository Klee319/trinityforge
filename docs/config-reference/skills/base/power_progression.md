```
  # 2026-07-25 PRG-08(ユーザー決定: SP供給不足の事故、増やす): POWERの唯一のEXP源は他スキルの
  # レベルアップ(exp_gain分/回)のみ。旧値100だと総供給1500レベル分(15スキル×Lv100)×100=150,000EXPで、
  # 上記exp_level_curveの累積 9L^2+791L=150,000 の解はL≈92(=SP≈95)にしか到達できず、
  # ノード総コスト295(排他考慮の実効取得可能232)に対し取得率は約32-41%だった(監査PRG-08)。
  # exp_gain=240へ引き上げ、総供給を360,000EXPに拡大: 9L^2+791L=360,000 の解はL≈160(=SP≈163)。
  # 163/232(排他考慮)≒70.3%・163/295(素の総コスト)≒55.3% — 「排他を考慮した上で7割程度」の目安を満たす。
  # PRG-09 (2026-07-25、ユーザー決定): プレステージ(スキルLv0リセット+SP返金)は何度でも周回できる仕様の
  # ままとし、代わりに「同じスキルを何回プレステージしたか」に応じて、そのスキルのレベルアップ1回が生む
  # POWER EXPを等比減衰させる。0.5 = 1周ごとに半減(初回到達=100%、1回プレステージ後の再到達=50%、
  # 2回目=25%、…)。初回到達(プレステージ0回、通常プレイの唯一の経路)は常にこの減衰の影響を受けない。
  # 幾何級数は必ず収束するため「無限に周回してもPOWER総量は発散しない」— 1スキルを無限に周回し続けても
  # そのスキルからの合計は exp_gain×100 ÷ この値 に収束する(既定0.5なら24,000÷0.5=48,000、
  # 15スキル全部を無限周回しても合計720,000EXPに収束=正規プレイの最大供給360,000のちょうど2倍)。
  # 0 にすると減衰なし(旧挙動、1スキルだけの周回でPOWERが無限に増える)に戻る後方互換スイッチ。
```
