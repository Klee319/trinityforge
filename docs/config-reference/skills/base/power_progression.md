## 2026-08-21 更新（ユーザー決定）— 上の PRG-09 の記述は「当時の値」

現行の出荷値は **`prestige_decay_rate: 0`（減衰なし）／`max_level: 242`**。
上の本文コメントは `0.5` 時代のものなので、**式の説明としては読めるが値は現行と違う**。

- **`prestige_decay_rate` は「減衰率」**。`(1 - rate)^プレステージ回数` を掛ける。
  **`1` にすると 0 倍＝プレステージしたスキルの POWER EXP が永久にゼロ**になる。
  「減衰なし（等倍）」にしたいときの値は **`0`**。ここを取り違えると意図と正反対になる。
- **`max_level: 242` の根拠**: 減衰が無い前提での総供給は
  「全 15 スキル × Lv100 × 2 周（初回＋プレステージ1回）× `exp_gain` 240」＝ **720,000EXP**。
  POWER 曲線の累積 `9L²+791L = 720,000` を解くと **L = 242.4**。
  つまり 242 は「各スキルを 1 回ずつプレステージし切ったところで、ちょうど上限に届く」値。
  **上限に張り付いた後の周回は SP が 1 も増えない**ので、`exp_gain` か周回想定を変えるなら
  `max_level` も一緒に動かすこと（この関係は
  `NativeSkillCatalogTest#powerCap_matchesTheSupplyOfOnePrestigeCycleForEverySkill` が縛っている）。
- **変更の反映には `/trinityforge reload` が要る。** プレイヤー行の `max_allowed_level` を
  更新するのは reload 時の `ProgressionCurveReconciler` だけで、ログインでは走らない。
