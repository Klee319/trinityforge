# afk.yml

出荷config `TrinityForge/src/main/resources/afk.yml` の本文コメント(先頭ヘッダを除く)をここに移設したもの。
config-editor で保存すると本文コメントは復元されないため([tools/config-editor/lib/yamlio.js](../../tools/config-editor/lib/yamlio.js) 参照)、運用ドキュメントとしてここに退避している。
**設定値そのもの(キー/値)はymlの方を参照。ここはコメント本文のみを収録し、移設前後でキー・値が完全一致することを確認済み。**

2026-07-27 に「使用制限スイッチ (use-requirements)」画面へ AFK セクションを追加したため、
このファイルは今後 editor から保存される。移設していなければ、その最初の保存で下記が全て消えていた。

## 本文コメント一覧(元のyml内での出現順)

### 直後: `enabled:`

```
# false にすると判定も報酬停止もキックも一切行わない(完全に無効)。
```

### 直後: `idle-seconds:`

```
# 無操作がこの秒数続いたらAFK扱いにする。既定300秒(5分)。
# 短すぎると正常プレイ(採掘の待ち・建築中の思考時間)を誤爆する。
```

### 直後: `kick-after-seconds:`

```
# AFK扱いになったプレイヤーを、無操作の合計がこの秒数に達した時点でキックする。
# 0 でキックしない(報酬停止だけ行う)。idle-seconds より大きい値にすること
# (小さい値を書いた場合は idle-seconds と同じ扱いへ丸める)。
```

補足(2026-07-27): Java 側(`AfkConfig#load`)は「0 以外で `idle-seconds` 未満」を警告ログ付きで
`idle-seconds` へ引き上げるが、**config-editor は保存時にエラーとして弾く**。
黙って丸められると「保存した値」と「実際の挙動」がずれるため。

### 直後: `kick-message:`

```
# キック時に表示するメッセージ(MiniMessage記法)。
```

### 直後: `notify:`

```
# true でAFK突入/復帰を本人へチャット通知する。
```

### 直後: `tab-suffix:` / `tab-suffix-text:`

```
# true でタブリストの名前に接尾辞を付ける(誰が放置中か他プレイヤーからも分かる)。
# 接尾辞のテキスト(MiniMessage記法)。tab-suffix: false のときは使われない。
```

### 直後: `exempt-permission:`

```
# この権限を持つプレイヤーはAFK判定の対象外(報酬停止もキックもされない)。
# 常駐させたい管理者/建築班向け。空文字にすると免除は無効。
```

補足: **空文字は「免除無効」という意味のある値**なので、他の文字列キーと違い既定値へ寄せない
(`AfkConfig#load` が `trimOrDefault` を使わず素直に読んでいるのはこのため)。

### 直後: `check-interval-ticks:`

```
# 判定タイマーの間隔(tick、20tick=1秒)。短くしても判定精度は上がらないので既定のままでよい。
```

補足: Java 側は 20 未満を 20 へ引き上げる。editor は 20 未満を保存時に弾く(理由は上と同じ)。

### 直後: `warn-before-seconds:` / `warn-title:` (2026-08-18 追加)

```
# AFK判定・自動キックの何秒前から予告カウントダウンを出すか。0 で予告しない。
# true で予告の開始時に画面中央のタイトルも出す(false ならアクションバーの数字だけ)。
```

補足: ユーザー報告「AFK が現状訪れるので title 等でカウントダウンか通知を表示してほしい」への対応。
**AFK 突入の通知は突入した後にしか出ない**ので、予告が無いとプレイヤーからは前触れなく報酬が止まったように見える。

- 予告は AFK 前は「AFK 判定まで」、AFK 中は「自動キックまで」を数える
  (`kick-after-seconds: 0` ならキックが起きないので AFK 中は何も出さない)。
- **カウントダウンは `check-interval-ticks` とは別に毎秒回る。** 判定タイマー(既定 40tick=2秒)に
  相乗りさせると「30, 28, 26, ...」と飛んでカウントダウンに見えないため。
- タイトルは**段階が変わった 1 回だけ**出す(毎秒出し直すと fadeIn がかかり直して点滅する)。
  毎秒更新するのはアクションバーの数字のほう。残り 5 秒以下で赤へ変わる。
- Java 側は `idle-seconds` 以上の値を警告ログ付きで `idle-seconds - 1` へ引き下げる
  (そのままだとログインした瞬間から常時カウントダウンが出る)。editor は保存時に弾く。

### 直後: `suppress:` および各サブキー

```
# AFK中に停止する報酬。個別に切り替えられる。
  # スキル(職業)EXP。NativeExperienceDispatcher を通る全経路が対象。
  # 管理コマンドによる付与(/tf progression exp)は別経路なので止まらない。
  # バニラ経験値。オーブ回収・かまど精錬・釣り・取引など PlayerExpChangeEvent 経由の全増加が対象。
  # TFが上乗せする追加ドロップ(mob-overrides / mob-level-table の drops)。
  # バニラ本来のドロップはここでは止めない(止めるとモブトラップが完全に死ぬため)。
  # 釣った魚の自動換金(fish-sell-toggle)。
```
