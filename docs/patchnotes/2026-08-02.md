## 🆕 新コンテンツ（今回の目玉）

計画していた追加コンテンツ7本柱のうち、残っていた分をすべて実装しました。
**新規アイテムは合計46点**、儀式レシピは 121件 → **167件**に増えています。

### 氷芯（ひょうしん）シリーズ 13種を追加しました

最上位帯（Lv100）の新シリーズです。**上限を上げるのではなく、既存の無限シリーズの隣に置く**
設計で、「攻撃力を捨てて出血を確実に通す」というコンセプトで差別化しています。

剣を例にした比較:

| | 無限の剣 | 氷芯の剣 |
|---|---|---|
| 攻撃力 | 37,800 | **26,460**（0.70倍） |
| 出血発生率 | — | **12%** |
| 出血ダメージ | — | **2,646** |
| スレッド枠 | 設定なし(0) | **2** |
| 耐久 | 1,218 | 1,218 |

素の攻撃力では無限シリーズに大きく劣りますが、**全品に出血が最低12%保証**され、
スレッド枠が2つあるので厳選で伸ばす余地があります。
ラインナップは剣・短剣・レイピア・槍・三叉槍・鎌・メイス・戦鎚・大剣・斧・大斧・弓・弩の13種。

**入手**: 儀式（核＝`16倍圧縮ウィザーローズ`、台座＝`64倍圧縮ブリーズロッド`・`硬質鋼材`・`エルダーガーディアンの棘`、ソース 30,000）

### 熾鉄（してつ）シリーズ 17種を追加しました

同じくLv100帯の新シリーズで、こちらは**「攻撃力で一歩譲るかわりに、まず壊れない」**型です。

| | 無限の剣 | 熾鉄の剣 |
|---|---|---|
| 攻撃力 | 37,800 | **32,130**（0.85倍） |
| 耐久 | 1,218 | **3,654**（3倍） |
| スレッド枠 | 設定なし(0) | **2** |

武器13種に加えて、**防具4部位（兜・胸当て・具足・靴）も追加**しました。防具側も耐久3倍・
スレッド枠2で、ダメージ軽減がわずかに上乗せされています。
**固定値の防御力（ダメージから直接引かれる値）には手を付けていません** — この数値はLv100帯で
発散しやすく、動かすと防御ラダーが壊れるためです。

**入手**: 儀式（核＝`9倍圧縮ネザライトブロック`、台座＝`59049倍圧縮石`・`6561倍圧縮エメラルドブロック`・`硬質鋼材`、
ソース 30,000／防具は 40,000）

### ロール専用装備8点を追加しました

**その職業に就いているときしか装備できない**装備です。
職業の変更にはクールタイム（120分）があるため、**「今日はこの職で遊ぶ」を選ぶ理由**を
作るのが目的です。**縦方向の強化にはしていません** — 性能は上の単発装備と同格で、
違いは「その職でないと装備できない」ことだけです。

| 職業 | 装備 | 効果 |
|---|---|---|
| 剣闘士 | 闘士の帯 | 貫通率 +4% |
| 魔導士 | 詠唱者の指輪 | マナ消費 -6% |
| 盾役 | 挑発の紋章 | 被ダメージ -2% / ノックバック耐性 +5% |
| 農家 | 実りの籠 | 収穫の追加ドロップ +10% |
| 釣り人 | 潮見の浮き | 釣り運 +2% |
| 坑夫 | 坑夫の灯 | 採掘運 +1% |
| 掘削者 | 均しの手袋 | 怪しいブロックの復活率 +1% |
| 木こり | 樵の砥石 | 一括伐採のクールタイム -15% |

すべてLv45・儀式（核＝`ジュエリーコア`、ソース 15,000）で作れます。
**指輪と砥石はオフハンドに持って効果を発揮する装飾品**です（インベントリに入れておくだけでは
効果がありません）。

### 「無限の源核」を設置できるようになりました

1億ソース到達の証明アイテムだった**無限の源核**が、**置いて機能するブロック**になりました。
設置すると**半径5ブロック以内のソースリンクの転送量・バッファ上限がどちらも2倍**になります。
複雑な多ブロック構造は不要で、置くだけです。**核は消費されず、右クリックで回収して置き直せます。**

### 「用途ゼロ」の素材30種すべてに使い道ができました

ダンジョンの印18種・コア4種・圧縮素材の行き止まり5種・スクラップなど、**入手できるのに使い道が
1つもなかった素材30種**が、今回で全部なくなりました。

- **ダンジョンの印18種** → 束縛者の鍵（任意の印を5種）
- **圧縮素材5種**（59049倍圧縮石／6561倍圧縮エメラルドブロック／9倍圧縮ネザライトブロック／64倍圧縮ブリーズロッド／16倍圧縮ウィザーローズ）
  → 氷芯・熾鉄シリーズの主素材
- **スクラップ** → 道具鍛冶の商人が「スクラップ8個 → 鉄スクラップ4個（＝鉄インゴット1個ぶん）」で引き取ります
- **略奪者の板金 / ピグリンの耳 / スケルトンホースの骨** → 醸造の材料（耐火・吐き気・移動速度）

## ⚔️ バランス調整

### 重量武器の火力を目標帯まで引き下げました

前回のパッチで重量武器を攻撃力+25%・攻撃速度-15%にしましたが、実測すると
**軽量武器に対して意図した水準を大きく超えていました**。
**目標帯である「軽量武器比 +15%」まで引き下げています。**
重量武器が軽量武器より一撃が重いという設計自体は変わりません。

### 弓・弩・トライデントで殴ったときの性能を下げました

遠隔武器を**近接武器として振り回す**と、本来の用途より強い場面がありました。
これらの武器の近接攻撃速度を最低値に設定し、**「殴るための武器ではない」ことをはっきりさせています。**
遠隔攻撃としての性能は変わりません。

### 束縛者ダンジョンの強さを段階ごとに明示しました

これまで束縛者ダンジョンのモブは**全モブ共通の成長式に任せきり**だったため、
**最終ボスなのに他ダンジョンの最終ボスと同じ強さ**になっていました。
召喚体・ミニボス・第2段階・最終段階の**4段階それぞれに体力と攻撃力を明示**しています
（第2段階で体力 12,127・攻撃 39.89 など）。

### ダンジョンボスの特殊攻撃を43体に拡大しました

特殊攻撃を持つボスが **34体 → 43体** になりました。
今回はエンチャント試練1〜9のボス9体に配っています（それまで特殊攻撃ゼロでした）。

## 🚨 不具合の修正

### スミス台にカスタム装備を置けなかった不具合を修正

`method: netherite` の12件（弓・弩・トライデント・メイス・ブレイズロッドなど）は
**スミス台のベース枠に物理的に置けませんでした**。
Minecraft 1.21.2 以降、スミス台に置けるアイテムは固定のタグではなく
**「登録済みスミスレシピの素材から組み直される集合」**で決まるため、
レシピを1件も登録していなかったこれらは永久に置けない状態でした。
`SmithingTransformRecipe` として正しく登録するようにしています。

### 儀式の経験値が最上位武器で「1」になっていた不具合を修正

儀式の経験値を素材ごとの計算に変えた際、**儀式で使う素材が経験値表に1つも載っていなかった**ため、
表に載っている安い素材だけが合計され、**儀式121件のうち57件が定額（100）を下回っていました。**
最悪のケースは束縛者の槍（ソース60,000の最上位武器）の **1 経験値**で、
**安い素材を1つ足すと経験値が100分の1になる**という逆転が起きていました。
儀式が使う素材86種を表に追加し、**121件すべてを正しく計算**できるようにしています。

### 防具立て・マネキンを殴ってレベリングできた不具合を修正

これらを叩き続けるだけで武器スキルの経験値が入っていました。
討伐経験値の計算そのもので0を返すようにしたため、**杖（魔法）経由でも抜けられません。**

### 召喚した馬まわりの不具合2件を修正

- 召喚馬から**鞍を抜き取ってアイテムを増やせる**不具合を塞ぎました
- その対策が原因で、**召喚馬に乗っている間ずっと自分のインベントリを開けなくなっていた**
  不具合を修正しました（騎乗中のEキーは「馬の装備画面」で、その下半分が自分の持ち物です）。
  乗っている本人だけは開けるようになり、鞍の抜き取りは引き続き塞がれています。

### 武器鍛冶の商人が空だった不具合を修正

武器鍛冶に追加したはずの取引2件が**実行時に丸ごと消え、職業まるごと空の商人**になっていました。
取引に使う素材が ArsPaper 側で定義されたアイテムだったのに、TrinityForge のカタログしか
参照していなかったのが原因です。

### 見た目が抜けていた装備36件を修正

リソースパックの台帳には登録されているのに**描画設定が抜けていた36件**が、
別シリーズの見た目で表示されていました。全件を正しく配線しています。

### 束縛者の設定コメントが事実と逆だった件を訂正

「体感値はここから±15%ぶれる」と書かれていましたが、実際には**個体差は完全に消えます**
（絶対値の上書きは、ばらつきを掛けた後に適用される置換のため）。

## 🛠️ 管理者向け（設定エディタ・config）

### スキル別の経験値ボーナスを設定できるようになりました

`伐採EXP+`・`農業EXP+`・`掘削EXP+` の3種をアイテムのステータスとして設定できます。
全スキル一律の経験値倍率とは**足し算で合成**され、掛け算は1回だけです。

> 「使用スキル」を分類の代わりに使わないでください。斧に `使用スキル: 伐採` と書くと
> 「伐採スキルが必要な斧」になるだけで、**その斧でモブを殴ったときに伐採EXPが入ります。**

### 装備に「専用職業」を設定できるようになりました

`use-role`（専用職業）を指定すると、その職業に就いているときだけ装備・使用できます。
戦闘職・補助職のどちらの枠で一致してもかまいません。使用スキル・使用レベルとは独立した条件で、
両方書けば両方を満たす必要があります。**未指定なら従来どおり職業を問いません。**

### モブのドロップを「倒したプレイヤーの職業」で絞れるようになりました

レベル帯の追加ドロップに `roles:` を書くと、その職業のプレイヤーが倒したときだけ落ちます。
**帯そのものには書けません**（帯ごと絞るとドロップ削除やバニラ経験値まで職業依存になるため）。
未指定なら従来どおり全員に落ちます。
