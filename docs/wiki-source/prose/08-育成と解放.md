# 育成と解放

## このページでわかること
- スキル（レベル成長）を上げる方法と、全16種のスキル一覧・EXPの稼ぎ方。
- 「戦闘レベル」の正体（＝戦闘系スキルのうち上位スキルから算出。装備ステは戦闘レベル自体には入らない）。
- グリフや装備を「使う」ために必要なレベル（解放システム）と、防具に付けられるエンチャント。

> このサーバーの成長は「自分（プレイヤー）のスキルを上げる」ことが中心です。あわせて装備の厳選もダメージに効きます。良い装備を拾っても、対応スキルが足りないと使えない・十分に活かせないことがあります。

---

## TrinityForgeスキルツリーとは
このサーバーの「レベル成長」はTrinityForgeが直接管理します。行動（戦う・掘る・釣る など）をすると、対応するスキルの経験値（EXP）が貯まり、スキルがレベルアップします。

- スキルは全部で16種類（戦闘5種＋採取生産9種＋このサーバー独自の2種）。
- 各スキルの上限はレベル100（総合だけ上限256）。
- スキルごとに得意分野があり、上げるほどそのジャンルが有利になります。

> スキル1つずつのEXPの稼ぎ方・上限・スキルツリーの中身は、実際の設定に基づいてまとめた[スキルツリー詳細](14-スキルツリー詳細.md)を参照してください。

### スキルツリーの形（主軸A〜E・派生・排他・プレステージ）
このサーバーのスキルツリーは、どれも同じ「並べ方の規則」で作られています。

- **主軸A〜E**: 各ツリーの背骨。解放レベルは A=10 / B=30 / C=50 / D=70 / E=90。
- **中間・派生ノード（枝）**: 主軸から伸びる枝。主軸の「間」は中間レベル（20/40/60/80）で解放。
- **ギリシャ文字路線（α/β/γ）**: 同じ親から出る同一グループの兄弟から
  **いずれか1つだけ**を選ぶ排他の選択。選択後は同じ路線の子ノードへ進めます。
- **合流ノード**: 複数の親ルートが設定されているノードは、そのうちどれか1つを
  解放していれば取得できます。
- **プレステージ I**: レベル100に到達すると解放される、ツリーごとの永続ボーナス。

このツリーはTrinityForge独自の設定（運営が管理する定義ファイル）で管理され、GUI・解放状態・バフもTrinityForge本体が適用します。運営はその設定を編集して、数値・名前・解放レベル・派生のつながりを調整できます。

`/skills`（短縮 `/s`、`/tf skills`も可）で54スロットのスキルツリーを開きます。
上段は9×5の座標ツリーで、周囲8方向の矢印から表示位置を移動できます。下段9枠は
選択中スキルが中央に来るスキル選択欄です。枝は親より上の層へ進む階層配置で、
排他候補は共通親から分岐し、合流は両方の経路を表示します。ノード間の線は
ロック中・解放可能・解放済みを色と直線/曲角/分岐テクスチャで区別します。
リソースパック未適用時もアイテムの種類と説明文だけで操作できます。

## 戦闘スキル（5種）
戦い方に応じて上がるスキルです。武器2種と弓は「戦闘レベル」にも影響します（後述）。防具2種は戦闘レベルには入らず、防御の強さに回ります。

| スキル（日本語名） | EXPの稼ぎ方（何をすると上がる） | 戦闘レベルへの影響 |
|---|---|---|
| 軽量武器 | 近接攻撃で与えたダメージ（ダメージ1点＝7EXP）。剣など軽い武器向き | あり（攻撃側） |
| 重量武器 | 近接攻撃で与えたダメージ（ダメージ1点＝10EXP）。斧など重い武器向き | あり（攻撃側） |
| 弓術 | 矢を当てる（弓は基礎30／クロスボウは基礎40＋遠いほど倍率） | あり（攻撃側） |
| 軽装備 | 軽い防具を着てダメージを受ける／与える＋装備している時間 | なし（防御側へ） |
| 重装備 | 重い防具を着てダメージを受ける／与える＋装備している時間 | なし（防御側へ） |

> 武器スキルは「与えたダメージ量」で伸びます。強い敵に大ダメージを通すほど早く育ちます。防具スキルは「着て戦い続ける」ことで自然に伸びます。

## 採取・生産スキル（9種）
モノづくりや採取で上がるスキルです。戦闘レベルには影響しませんが、生活・クラフトの土台になります。

| スキル（日本語名） | EXPの稼ぎ方（何をすると上がる） |
|---|---|
| 総合（集約メタ） | 他のスキルが1レベル上がるたびに加算（レベルアップ回数×100）。全スキル共通のスキルポイント源。上限256 |
| 採掘 | 鉱石や石を壊す（自分で設置したブロックは無効） |
| 切削 | 土系ブロックを壊す＋考古ブラシ |
| 伐採 | 原木や木材を壊す＋樹皮はぎ |
| 農業 | 作物の収穫・動物の繁殖・毛刈り など |
| 釣り | 魚などを釣り上げるたびに |
| 鍛冶 | 素材の耐久を使って加工するほど |
| エンチャント | 消費した経験値の一部が変換＋エンチャント種別ごとの基礎値 |
| 錬金 | 醸造したポーションの品質に応じて |

> 総合は「他のスキルを上げれば勝手に上がる」まとめ役のスキルです。何かを育てていれば自然に伸びます。

## このサーバー独自のスキル（2種）
このサーバー独自の特別なスキルが2つあります。

| スキル（日本語名） | 何のスキルか | EXPの稼ぎ方 | 戦闘レベルへの影響 |
|---|---|---|---|
| Ars魔法（魔法柱） | 魔法の腕前。上げると戦闘レベルに反映され、マナ上限や再生の伸びしろにも関わる | 呪文（グリフを組んだスペル）を詠唱すると成長 | あり（魔法側） |
| Ars鍛冶 | 魔道具づくりの腕前。この値が「作った魔道具の品質」を決める | 魔道具（魔法の装備）をクラフトすると成長 | なし（生産用） |

> 「Ars魔法」を上げると、魔法使いとしての戦闘レベルが上がります。「Ars鍛冶」は戦闘力には関係なく、良い魔道具を自作するための職人スキルです。呪文を詠唱すると「Ars魔法」のEXPが、魔道具をクラフトすると「Ars鍛冶」のEXPが入ります。

## 戦闘レベル
「戦闘レベル」は、あなたの総合的な戦闘力をあらわす数字（0〜100）です。ダンジョンの入場条件や、一部の装備の使用制限に使われます。

### 対象になる4スキル
戦闘レベルは、次の4つのスキルのレベルから決まります。

| 戦闘レベルに使うスキル | 種類 |
|---|---|
| 軽量武器 | 物理 |
| 重量武器 | 物理 |
| 弓術 | 物理 |
| Ars魔法 | 魔法 |

### どう決まるのか（上位スキルで決まる「柱」方式）
昔の「4スキルの平均」ではなく、**伸びている上位スキルだけを見て決める方式**になりました。イメージは「一番得意な戦い方を評価する」計算です。

4つの数え方を計算し、**大きいほうを採用**します。

| 数え方 | 計算 |
|---|---|
| 上位1スキルの柱 | もっとも高い1スキルのレベルをそのまま使う |
| 上位2スキルの柱 | 高いほうから2スキルのレベルを足して 1.5 で割る |
| 上位3スキルの柱 | 高いほうから3スキルのレベルを足して 2.1 で割る |
| 上位4スキルの柱 | 高いほうから4スキルのレベルを足して 2.8 で割る |

この大きいほうに倍率（現在1.0）をかけ、四捨五入して 0〜100 に収めた数字が戦闘レベルです。

> 式で書くと: `戦闘レベル = 四捨五入( 1.0 × max(上位1÷1.0, 上位2合計÷1.5, 上位3合計÷2.1, 上位4合計÷2.8) )`（下限0・上限100）。上位いくつを見るか・割る数・倍率は、運営が設定で調整できます。

### 具体例（どう変わるか）

| 育て方 | 各スキルのレベル | 戦闘レベル |
|---|---|---|
| 1スキルに特化 | Ars魔法100・他0 | 100（＝100÷1.0） |
| 2スキルを均等に | 軽武器75・重武器75 | 100（＝150÷1.5） |
| 3スキルを均等に | 軽武器70・重武器70・弓70 | 100（＝210÷2.1） |
| 4スキルを均等に | 4スキル各50 | 71（＝200÷2.8、四捨五入） |

- 純特化の100は100のままです。未修得スキルのために不利になることはありません。
- 複数の戦闘スキルを育てた場合も、上位2・3技能の柱で同水準を目指せます。

### 大事なポイント
- **防具スキル（軽装備・重装備）は戦闘レベルに入りません。** 防御の強さは別の仕組みで扱われます。
- **装備の強さは戦闘レベルそのものには入りません**（どんなに良い武器を持っていても、スキルが低ければ戦闘レベルは上がりません）。一方で、実際のダメージには装備ステ（攻撃力など）も乗るため、スキル育成と厳選の両方が重要です。

> この「上位スキルの柱」方式は正式な仕様として実装済みです。ただし各数値（倍率・割る数・上限）は調整中（暫定）です。各スキルの詳細は[スキルツリー詳細](14-スキルツリー詳細.md)、実装状況は[実装状況と注意点](12-実装状況と注意点.md)を参照。

## 解放システム（使用ゲート方式）
このサーバーの「解放」は、少し変わった考え方をしています。

> グリフや装備の「入手」は自由。でも「使う」には対応スキルのレベル（解放条件）が必要。

つまり、強い装備や呪文グリフは早く手に入れても構いませんが、実際に使いこなすにはスキルを育てておく必要がある、という設計です。

### 装備の使用レベル制限
一部の装備には「使用レベル制限」が設定されています。制限のある装備を、条件を満たさずに使おうとすると弾かれます。

- 条件を満たさない武器で近接攻撃、または弓・クロスボウ・トライデントを発射すると、その動作はキャンセルされ、画面下に「この装備を使うには ○○ Lv△△ が必要です」と表示されます。
- 制限のない装備・素手はいつでも使えます。
- 参照されるのはサーバーに保存されたあなたのスキルレベルで、装備の強さは無関係です。

> **この使用レベル制限は現在、実際に有効になっています。** 武器・防具は、素材や魔道防具のランクが上がるほど必要スキルレベルも段階的に上がる設計で、多くのアイテムにすでに具体的な必要レベルが設定されています。採掘・伐採などのツールにはこの制限を掛けるしくみ自体はありますが、今のところ具体的な要求レベルはほぼ未設定です。近接武器・遠隔武器（弓・クロスボウ・トライデント）に加え、**防具の装備もチェックされます**（`ArmorUseGateListener`）。魔法の杖・魔法書側のゲートはアイテム設定次第ですが、プレイヤー向けには「使えない装備は弾かれる」と考えておけば十分です。正確な必要レベルの一覧は運営の設定次第で変わるため、迷ったら実際にその装備を使ってみて確認してください。詳しくは[実装状況と注意点](12-実装状況と注意点.md)。

### 呪文グリフの使用ゲート（二段構え）
呪文を組み立てるグリフにも、「使うのに解放条件（perk）が必要」という仕組みがあります。安全のため二段階でチェックされます。

| 段階 | いつ | 何が起きるか |
|---|---|---|
| 作成時ブロック | スペル作成GUIでグリフを組む時 | 条件を満たさないグリフは組み込めない（保存も拒否） |
| 発動時の不発 | スペルを詠唱した時 | 条件を満たさないグリフが混じっていると、マナを消費する前に不発になる |

共有スペル（後述の「共有」エンチャント）を使うときも、「使う本人」の解放条件は必ずチェックされます。

> ただし現状、グリフの解放条件を書き込む仕組みはまだ運営側で設定されておらず、初期状態では全グリフが誰でも自由に使えます（二段判定は常に素通り）。一方で、上で説明した装備そのものの使用レベル制限（武器・防具・魔法の杖）はすでに有効に設定されています。グリフの解放条件と、装備自体の使用レベル制限は別の仕組みなので、混同しないよう注意してください。詳しくは[実装状況と注意点](12-実装状況と注意点.md)。

## エンチャント（ArsPaper 独自）
このサーバーには、バニラとは別の独自エンチャントが4種類あります。エンチャントテーブルには出ません。入手は儀式で「エンチャント本」を作り、金床（かなとこ）で装備に付けます。

| エンチャント（日本語名） | 最大Lv | 付けられる対象 | 効果 |
|---|---|---|---|
| マナ再生 | 3 | 魔道防具 | 防具を着ている間、一定間隔でマナが自然回復（Lv1:+1／Lv2:+3／Lv3:+6） |
| マナ上昇 | 3 | 魔道防具 | 最大マナが増える（Lv1:+15／Lv2:+30／Lv3:+50） |
| 回生（そうるばうんど） | 1 | 耐久のある装備 | 装備が壊れる一撃を1回だけ肩代わり。エンチャントを消費して装備を完全修復（1回限り） |
| 共有（しぇあ） | 1 | スペルブック専用 | 組んだスペルを他の人にも詠唱させられる共有マーカー |

### 付け方（儀式→金床）
1. 儀式でエンチャント本を作る（回生の本は少し重い素材が必要）。
2. 金床で「装備＋エンチャント本」を合成して付与する。
3. 本は1個消費。合成のコストは回生だけ高め（他は軽い）。

補足:
- マナ再生・マナ上昇は「魔道防具にだけ」付きます。共有は「スペルブックにだけ」、回生は「耐久のある装備」に付きます。
- 回生が付いた装備は「本人のもの」として記録され、壊れる瞬間に一度だけ復活します。もう一度使いたい場合は、また儀式で本を作って付け直します。

## 自分の育成状況を確認する
`/trinityforge stats`（短縮形 `/tf stats`）で、自分の育成状況をまとめて確認できます（自分のぶんだけ・見るだけのコマンド）。

表示される内容:
- 戦闘レベル（上で説明した「上位スキルの柱」方式で算出）。
- スキルレベル（戦闘レベルに使う各スキルの現在レベル）。
- 今持っている武器の品質と、そこから導かれる攻撃ステータス。
- 装備している防具の合計ステータス（防御・厳選ぶんの合算）。

> このコマンドには、後述のプレステージ回数やロールは表示されません。プレステージは `/skills` の各ツリーから確認・実行します。

## プレステージとロール（職業）の現状
プレステージは実装済みです。対象スキルが設定レベル（通常100）へ到達するとツリー上端に
プレステージノードが解放されます。通常ノードと同じく2回クリックして実行します。

- 対象スキルのレベル・EXPと通常Perkをリセットします。
- 使用済みポイントを返却し、プレステージ回数と永続ボーナスをまとめてサーバー側のデータに安全に保存します（保存中に他の操作が割り込んでも壊れない方式）。
- ツリーごとの固有名と永続ボーナスの内容は、運営の設定で管理されています。

ロール（剣闘士・魔術師・タンク、補助職の斥候・農夫・採掘夫）は実装済みです。補助職のポーション効果と対応スキルEXP+20%は、変更時を含めて同期されます。各ツリーのプレステージ内容は[スキルツリー詳細](14-スキルツリー詳細.md)、ロールの注意点は[実装状況と注意点](12-実装状況と注意点.md)を参照してください。

## つまずきやすいポイント（まとめ）
- 戦闘レベルは「スキルレベル」から決まり、良い装備を拾っても戦闘レベル自体は上がらない。ただし実際のダメージには装備ステも乗る。
- 戦闘レベルは「上位スキルの柱」方式で実装済み。ただし各数値は調整中（暫定）。
- グリフ・レシピの解放条件は、初期状態では設定が空のため全員が素通りで自由に使える。一方、装備そのものの使用レベル制限（武器・防具など）はすでに有効で、多くのアイテムに具体的な必要レベルが設定されている。
- 装備の使用制限は、近接・遠隔・ツール・防具まで対象になり得るしくみだが、実際に要求レベルが設定されているのは現状、主に武器・防具（魔道防具含む）。
- プレステージは `/skills` のツリー上端にあるノードを2回クリックして実行する。ロールの補助効果とEXP倍率も稼働する。

詳しい実装状況・矛盾点・今後の予定は、すべて[実装状況と注意点](12-実装状況と注意点.md)にまとめています。
