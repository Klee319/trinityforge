# 育成と解放

## このページでわかること
- スキル（レベル成長）を上げる方法と、全16種のスキル一覧・EXPの稼ぎ方。
- 「戦闘レベル」の正体（＝戦闘系スキルのうち上位スキルから算出。装備ステは戦闘レベル自体には入らない）。
- グリフや装備を「使う」ために必要なレベル（解放システム）と、防具に付けられるエンチャント。

> このサーバーの成長は「自分（プレイヤー）のスキルを上げる」ことが中心です。あわせて装備の厳選もダメージに効きます。良い装備を拾っても、対応スキルが足りないと使えない・十分に活かせないことがあります。

## TrinityForgeスキルツリーとは
このサーバーの「レベル成長」はTrinityForgeが直接管理します。行動（戦う・掘る・釣る など）をすると、対応するスキルの経験値（EXP）が貯まり、スキルがレベルアップします。

- スキルは全部で16種類（戦闘5種＋採取生産9種＋このサーバー独自の2種）。
- 各スキルの上限はレベル100（**総合だけ上限242**）。
- スキルごとに得意分野があり、上げるほどそのジャンルが有利になります。

> スキル1つずつのEXPの稼ぎ方・上限・スキルツリーの中身は、実際の設定に基づいてまとめた[スキルツリー詳細](14-スキルツリー詳細.md)を参照してください。

### スキルツリーの形（主軸A〜E・派生・排他・プレステージ）
このサーバーのスキルツリーは、どれも同じ「並べ方の規則」で作られています。

- **主軸A〜E**: 各ツリーの背骨。解放レベルは A=10 / B=30 / C=50 / D=70 / E=90。
- **中間・派生ノード（枝）**: 主軸から伸びる枝。主軸の「間」は中間レベル（20/40/60/80）で解放。
- **ギリシャ文字路線（α/β/γ）**: 同じ親から出る同一グループの兄弟から
  **いずれか1つだけ**を選ぶ排他の選択。選択後は同じ路線の子ノードへ進めます。
- **合流ノード**: 複数の親ルートが設定されているノードは、そのうちどれか1つを
  解放していれば取得できます。
- **プレステージ**: 対象スキルが設定レベル（通常100）へ到達すると解放される、ツリーごとの永続ボーナス。**1回きりではなく、ツリーごとに複数回の上限（武器3ツリーは3回、防具・生産系は5回）が設定されています。**

このツリーはTrinityForge独自の設定（運営が管理する定義ファイル）で管理され、GUI・解放状態・バフもTrinityForge本体が適用します。運営はその設定を編集して、数値・名前・解放レベル・派生のつながりを調整できます。

`/skills`（短縮 `/s`、`/tf skills`も可）で54スロットのスキルツリーを開きます。
上段は9×5の座標ツリーで、周囲8方向の矢印から表示位置を移動できます。下段9枠は
選択中スキルが中央に来るスキル選択欄です。枝は親より上の層へ進む階層配置で、
排他候補は共通親から分岐し、合流は両方の経路を表示します。ノード間の線は
ロック中・解放可能・解放済みを色と直線/曲角/分岐テクスチャで区別します。
リソースパック未適用時もアイテムの種類と説明文だけで操作できます。

画面左下の時計アイコンから**「パーク一覧モード」**に切り替えると、現在のツリーのパークだけを一覧の体裁で並べて確認できます。押した場所（表示位置）は次回開いたときも復元されます。

## 戦闘スキル（5種）
戦い方に応じて上がるスキルです。武器2種と弓は「戦闘レベル」にも影響します（後述）。防具2種は戦闘レベルには入らず、防御の強さに回ります。

| スキル（日本語名） | EXPの稼ぎ方（何をすると上がる） | 戦闘レベルへの影響 |
|---|---|---|
| 軽量武器 | 敵の討伐（討伐EXP基礎値20＋敵の最大HPに応じた加算）。剣など軽い武器向き | あり（攻撃側） |
| 重量武器 | 敵の討伐（討伐EXP基礎値30＋敵の最大HPに応じた加算）。斧など重い武器向き | あり（攻撃側） |
| 弓術 | 敵の討伐（討伐EXP基礎値25＋敵の最大HPに応じた加算） | あり（攻撃側） |
| 軽装備 | 軽い防具を着てダメージを受ける／与える＋装備している時間 | なし（防御側へ） |
| 重装備 | 重い防具を着てダメージを受ける／与える＋装備している時間 | なし（防御側へ） |

- 武器3スキル（軽量武器・重量武器・弓術）はいずれも「敵を倒したとき」にEXPが入る討伐ベースの方式で統一されています。基礎値は重量武器が最も高く、次いで弓術、軽量武器の順です。敵の最大HPに比例した加算（1につき0.188EXP）が乗るため、強い敵ほど1体あたりのEXPが大きくなります。
- **モブ定義（種別ごとの倍率）に載っていない敵は、討伐してもEXPが入りません。** ハチ・イルカ・ヤギ・ゴーレム・オオカミなど、敵対しない・非戦闘用のモブがこれに該当します。繁殖させてもスキルは伸びません。
- **戦闘スキルのEXPは、ダンジョンの中でも外でも減額されます**（2026-08-21 に改定）。

  | 場所 | 倍率 |
  |---|---|
  | ダンジョンの中 | **×0.375** |
  | ダンジョンの外（オーバーワールド・資源サーバーを含む） | **×0.1875** |

  つまり**ダンジョン内は外のちょうど2倍**です。以前は「内は等倍・外は×0.25」でしたが、ダンジョン内側にも倍率を掛けられるようになり、両方が絞られています。掛かる先は**武器（軽量・重量・弓）・Ars魔法の討伐EXP・防具の被弾EXP**で、家畜討伐の農業EXPや採取EXPは対象外です。
- 防具スキルは「着て戦い続ける」ことで自然に伸びます。**ただし相手が自分の防具スキルより大きく高レベルだと、防具EXPにも足きりが掛かります**（下の[EXPが減る3つのしくみ](#expが減る3つのしくみ)参照）。

## 採取・生産スキル（9種）
モノづくりや採取で上がるスキルです。戦闘レベルには影響しませんが、生活・クラフトの土台になります。

| スキル（日本語名） | EXPの稼ぎ方（何をすると上がる） |
|---|---|
| 総合（集約メタ） | 他のスキルが1レベル上がるたびに加算（レベルアップ1回につき **240EXP**）。全スキル共通のスキルポイント源。**上限242** |
| 採掘 | 鉱石や石を壊す（自分で設置したブロックは無効） |
| 切削 | 土系ブロックを壊す＋考古ブラシ |
| 伐採 | 原木や木材を壊す＋樹皮はぎ |
| 農業 | 作物の収穫・動物の繁殖・毛刈り など。**2026-08-21 に畑の作物が40%・家畜討伐が80%へ圧縮**されました（効率が良すぎたため） |
| 釣り | 魚などを釣り上げるたびに |
| 鍛冶 | 素材の耐久を使って加工するほど |
| エンチャント | 消費した経験値の一部が変換＋エンチャント種別ごとの基礎値 |
| 錬金 | 醸造したポーションの種類・素材・品質に応じて。**自分で醸造台に入れると ×2、ホッパーで自動醸造すると ×0.25**（放置醸造は割に合いません）。品質1つにつき +5%。カスタムポーションは**使った素材ごと**にEXPが決まります |

> 総合は「他のスキルを上げれば勝手に上がる」まとめ役のスキルです。何かを育てていれば自然に伸びます。上限は **242**（2026-08-21 に 160 から引き上げ）。242 という数字は「全15スキル × Lv100 × プレステージ2周ぶん」を総合の必要EXP曲線に流したときの到達点で、**育て切ればちょうど使い切れる**ように決められています。

## このサーバー独自のスキル（2種）
このサーバー独自の特別なスキルが2つあります。

| スキル（日本語名） | 何のスキルか | EXPの稼ぎ方 | 戦闘レベルへの影響 |
|---|---|---|---|
| Ars魔法（魔法柱） | 魔法の腕前。上げると戦闘レベルに反映され、マナ上限や再生の伸びしろにも関わる | 敵の討伐（討伐EXP基礎値20＋敵の最大HPに応じた加算） | あり（魔法側） |
| Ars鍛冶 | 魔道具づくりの腕前。この値が「作った魔道具の品質」を決める | 魔道具（魔法の装備）をクラフトすると成長 | なし（生産用） |

> 「Ars魔法」を上げると、魔法使いとしての戦闘レベルが上がります。「Ars鍛冶」は戦闘力には関係なく、良い魔道具を自作するための職人スキルです。討伐すると「Ars魔法」のEXPが、魔道具をクラフトすると「Ars鍛冶」のEXPが入ります。

## スキルのEXPカーブは統一されていません

各スキルの「次のレベルに必要なEXP量」の式（カーブ）は**2系統**です。**バニラ由来の13スキル（軽量武器・重量武器・弓術・軽装備・重装備・採掘・切削・伐採・農業・釣り・鍛冶・エンチャント・錬金）はすべて `2^(Lv/8)` で統一**されており、**TF独自のArs魔法・Ars鍛冶の2本だけが `2^(Lv/7.6)`**（Lv100の1レベルぶんで約1.6倍重い）です。総合（POWER）はさらに別で、レベルに比例する独自の式です。

- **分母が大きい `2^(Lv/8)` のほうが必要EXPは少なくなります。** Lv100 の1レベルぶんで比べると 434,846 に対して 685,860（分母8側は約6割）で、差は高レベルほど開きます。
- つまり **軽量武器・重量武器・軽装備・重装備・伐採の5本のほうが、高レベルまで伸ばすのは軽い**ということです。

## EXPが減る3つのしくみ

場所の倍率（上のダンジョン内外）とは別に、**EXPを削る3つのしくみ**が動いています。「思ったより経験値が入らない」と感じたら、まずこの3つを疑ってください。

### 1. レベル差の足きり（格上狩りの抑制）

**倒した相手が自分より大きく高レベルだと、もらえるEXPとドロップが削られます。** 低レベルのままハメ殺しやデスルーラーで高レベルの敵を狩るのを抑えるためのしくみです。

| 対象 | 比較に使う「自分のレベル」 | 削られ方 |
|---|---|---|
| **職業（スキル）EXP** | **そのEXPが入る職業のレベル** | 15差から絞り始め、1レベルごとに約6.7%ずつ減って**30差で0** |
| バニラの経験値オーブ | 戦闘レベル | 同上 |
| TFの追加ドロップ | 戦闘レベル | **20差で完全に出なくなる** |

- **職業EXPだけは「その職業のレベル」で比べます**（2026-08-22 に変更）。軽量武器の討伐EXPなら軽量武器スキルのレベル、魔法の討伐EXPなら Ars魔法のレベル、防具のEXPなら防具スキルのレベルです。
  それ以前は全部「戦闘レベル」で比べていたため、**軽量武器100の特化プレイヤーでも戦闘レベルは67**なので、Lv100の敵とのレベル差が0ではなく33と判定され、EXPが削られていました。逆に「軽量武器80・魔法1」の人が高レベルダンジョンで魔法を振ると、判定が魔法1ではなく戦闘Lv53で行われ、抑制がまったく効いていませんでした。両方が同時に直っています。
- 目安（EXP）: **15差＝満額 / 20差＝0.67倍 / 25差＝0.33倍 / 30差以上＝0**。
- ⚠️ **パーティで連れて行ってもらっても免除されません。** レベル差だけで判定します（免除を入れると「低レベルを連れて行くだけ」で抑制を回避できてしまうため）。

### 2. 日次逓減（1日に稼ぎすぎると薄まる）

**直近24時間に同じスキルで稼いだ量が増えるほど、そのスキルのEXP取得量が薄まります。**

| 項目 | 値 |
|---|---|
| 何ごとに1段下がるか | そのスキルで **100,000EXP** 稼ぐごと |
| 1段あたり | **×0.9** |
| 下限 | **50%**（これ以上は薄まらない） |
| 強制解除 | 逓減が**発動した時刻から24時間**で、蓄積ごとリセットして100%へ戻る |

- 強制解除の数え始めは「最後にEXPを得た時刻」ではなく「**逓減が発動した時刻**」です。稼ぎ続けていても24時間経てば必ず解除されます。
- 以前は自然回復だけだったため、24時間放置しても約37%が残り「一度下がるとずっと下がったまま」に感じる状態でした。2026-08-19 にこの強制解除が入っています。

### 3. 同一地点の逓減（TT・放置狩りの抑制）

**同じ場所で狩り続けると倍率が落ちます。**

| 項目 | 値 |
|---|---|
| 判定範囲 | 半径 **16ブロック** |
| 判定時間 | 直近 **300秒（5分）** |
| 満額で狩れる数 | **80体まで** |
| 超過1体につき | **−2%** |
| 下限 | **40%** |
| ダンジョンワールド | **対象外**（この逓減は掛かりません） |

- 80体/5分 は「3.75秒に1体を1箇所から動かずに倒し続ける」密度です。手で集めて刈るプレイでは届きませんが、湧き機構のあるTTなら確実に届きます。
- 以前は「30体で減り始め48体で10%」だったため、エンドのエンダーマンやネザーのピグリンを普通に集めて狩るだけで下限に張り付いていました。2026-08-19 に大幅に緩められています。
- このしくみの狙いは「稼げなくする」ことではなく「**1箇所に居座るのを割に合わなくする**」ことです。総量の頭打ちは上の日次逓減が担当します。

### ダンジョンは「選んだ挑戦レベル」で報酬が増減する

ダンジョン（EliteMobsのインスタンス）は入場時に挑戦レベルと難易度を選びます。**倒したモブのレベルが高いほど、ドロップとEXPが増えます。**

| モブのレベル | TF追加ドロップ | 撃破EXP |
|---|---|---|
| 15以下 | ×0.70（下限） | ×0.80（下限） |
| 20 | ×0.76 | ×0.88 |
| 30 | ×0.92 | ×0.96 |
| **35** | **×1.00（基準）** | **×1.00（基準）** |
| 40 | ×1.08 | ×1.04 |
| 50 | ×1.24 | ×1.12 |
| 60 | ×1.40 | ×1.20 |
| 70以上 | ×1.50（上限） | ×1.25（上限） |

- 効くのは**ダンジョンの中で倒したモブだけ**です。オーバーワールドの高レベルモブには一切掛かりません。
- 判定に使うのは「倒したモブのレベル」で、自分とのレベル差ではありません。
- 難易度（normal / hard / mythic）はモブレベルを −5／±0／+5 動かすので、**難易度を1段上げると報酬も1段上がります**。
- 上のレベル差の足きりを掛けた**あと**に乗ります。足きりで0になったキルは、ここで増やしても0のままです。

## スキルポイント

スキルツリーのパークを解放するためのスキルポイントは、次の式で決まります。

> スキルポイント総数 ＝ **初期3点** ＋ 総合（POWER）レベル ÷ 1（切り捨て）

つまり「毎レベル+1」ではなく、**最初から3点持った状態でスタートし、そこに総合レベル分が加算**されます（既定では総合1レベルにつき1点）。総合の上限が242なので、**最終的に手に入るスキルポイントは最大245点**です。

> **プレステージをしても総合（POWER）のEXPは減りません**（2026-08-21 に減衰率0へ変更）。プレステージで対象スキルのレベルは戻りますが、そこまでに積み上げた総合レベル＝スキルポイントは失われません。

## 戦闘レベル
「戦闘レベル」は、あなたの総合的な戦闘力をあらわす数字（0〜100）です。ダンジョンの入場条件や、一部の装備の使用制限に使われます。

戦闘レベルは、複数の戦闘系スキルのレベルから算出される値で、特定の1スキルだけで決まるものではありません。「一番得意な戦い方」を評価する計算式になっています。

### 対象になる4スキル
戦闘レベルは、次の4つのスキルのレベルから決まります。

| 戦闘レベルに使うスキル | 種類 |
|---|---|
| 軽量武器 | 物理 |
| 重量武器 | 物理 |
| 弓術 | 物理 |
| Ars魔法 | 魔法 |

### どう決まるのか（上位スキルで決まる「柱」方式）
昔の「4スキルの平均」ではなく、**伸びている上位スキルだけを見て決める方式**になりました。イメージは「一番得意な戦い方を評価する」計算です。

4つの数え方を計算し、**大きいほうを採用**します。

| 数え方 | 計算 |
|---|---|
| 上位1スキルの柱 | もっとも高い1スキルのレベルを 1.5 で割る |
| 上位2スキルの柱 | 高いほうから2スキルのレベルを足して 2 で割る |
| 上位3スキルの柱 | 高いほうから3スキルのレベルを足して 2.5 で割る |
| 上位4スキルの柱 | 高いほうから4スキルのレベルを足して 3 で割る |

この大きいほうに倍率（現在1.0）をかけ、四捨五入して 0〜100 に収めた数字が戦闘レベルです。

> 式で書くと: `戦闘レベル = 四捨五入( 1.0 × max(上位1÷1.5, 上位2合計÷2, 上位3合計÷2.5, 上位4合計÷3) )`（下限0・上限100）。上位いくつを見るか・割る数・倍率は、運営が設定で調整できます。

### 具体例（どう変わるか）

| 育て方 | 各スキルのレベル | 戦闘レベル |
|---|---|---|
| 1スキルに特化 | Ars魔法100・他0 | 67（＝100÷1.5、四捨五入） |
| 2スキルを均等に | 軽武器75・重武器75 | 75（＝150÷2） |
| 3スキルを均等に | 軽武器70・重武器70・弓70 | 84（＝210÷2.5、四捨五入） |
| 4スキルを均等に | 4スキル各50 | 67（＝200÷3、四捨五入） |

- 除数（1.5／2／2.5／3）は現行設定の値です。特化と分散の差は小さめに調整されており、複数の戦闘スキルを育てても十分なスコアを狙えます。

### 大事なポイント
- **防具スキル（軽装備・重装備）は戦闘レベルに入りません。** 防御の強さは別の仕組みで扱われます。
- **装備の強さは戦闘レベルそのものには入りません**（どんなに良い武器を持っていても、スキルが低ければ戦闘レベルは上がりません）。一方で、実際のダメージには装備ステ（攻撃力など）も乗るため、スキル育成と厳選の両方が重要です。

> この「上位スキルの柱」方式は正式な仕様として実装済みです。ただし各数値（倍率・割る数・上限）は調整中（暫定）です。各スキルの詳細は[スキルツリー詳細](14-スキルツリー詳細.md)、実装状況は[実装状況と注意点](12-実装状況と注意点.md)を参照。

## 解放システム（使用ゲート方式）
このサーバーの「解放」は、少し変わった考え方をしています。

> グリフや装備の「入手」は自由。でも「使う」には対応スキルのレベル（解放条件）が必要。

つまり、強い装備や呪文グリフは早く手に入れても構いませんが、実際に使いこなすにはスキルを育てておく必要がある、という設計です。

### 装備の使用レベル制限
一部の装備には「使用レベル制限」が設定されています。制限のある装備を、条件を満たさずに使おうとすると弾かれます。

- 条件を満たさない武器で近接攻撃、または弓・クロスボウ・トライデントを発射すると、その動作はキャンセルされ、画面下に「この装備を使うには ○○ Lv△△ が必要です」と表示されます。
- 制限のない装備・素手はいつでも使えます。
- 参照されるのはサーバーに保存されたあなたのスキルレベルで、装備の強さは無関係です。

必要レベルは、素材・ランクが上がるほど段階的に上がる設計です。武器は木0／石5／銅15／鉄25／金35／ダイヤ45／ネザライト60、防具は革0／銅0／チェイン10／亀10／鉄15／金35／ダイヤ45／ネザライト60、さらに上位のカスタム帯には80・100の段があります。

> **この使用レベル制限は現在、実際に有効になっています（近接攻撃・遠隔武器の発射が対象）。** ただし**防具の装備と、魔法の触媒（Ars）の詠唱については、ゲートのしくみ自体はまだ機能していません。** 装備・触媒に必要レベルが刻まれていても、着用・詠唱そのものはブロックされないので注意してください。ツール（採掘・伐採など）には制限を掛けるしくみ自体はありますが、今のところ具体的な要求レベルはほぼ未設定です。正確な必要レベルの一覧は運営の設定次第で変わるため、迷ったら実際にその装備を使ってみて確認してください。詳しくは[実装状況と注意点](12-実装状況と注意点.md)。

### 呪文グリフの使用ゲート（二段構え）
呪文を組み立てるグリフにも、「使うのに解放条件（perk）が必要」という仕組みがあります。安全のため二段階でチェックされます。

| 段階 | いつ | 何が起きるか |
|---|---|---|
| 作成時ブロック | スペル作成GUIでグリフを組む時 | 条件を満たさないグリフは組み込めない（保存も拒否） |
| 発動時の不発 | スペルを詠唱した時 | 条件を満たさないグリフが混じっていると、マナを消費する前に不発になる |

共有スペル（後述の「共有」エンチャント）を使うときも、「使う本人」の解放条件は必ずチェックされます。

> ただし現状、グリフの解放条件を書き込む仕組みはまだ運営側で設定されておらず、初期状態では全グリフが誰でも自由に使えます（二段判定は常に素通り）。一方で、上で説明した装備そのものの使用レベル制限（武器・防具・魔法の杖）は近接・遠隔の武器についてはすでに有効に設定されています。グリフの解放条件と、装備自体の使用レベル制限は別の仕組みなので、混同しないよう注意してください。詳しくは[実装状況と注意点](12-実装状況と注意点.md)。

## 武器スキルツリーのバフに関する注意（重要）

**軽量武器・重量武器・弓術の3ツリーで取ったバフは、「その武器種をメインハンドに持っているときだけ」効きます。** 軽量武器ツリーを全部取っても、メインハンドに斧（重量武器）を持っていれば軽量武器ツリーのバフは一切乗りません。

これは育成方針に直結する注意点です。**複数の武器種のツリーを並行して育てても、実際に戦闘中に恩恵を受けられるのは「いま手に持っている武器種のツリー」だけ**なので、メインで使う武器種を先に決めてから、そのツリーへ集中投資するほうが効率的です。

## エンチャント（ArsPaper 独自）
このサーバーには、バニラとは別の独自エンチャントが4種類あります。エンチャントテーブルには出ません。入手は儀式で「エンチャント本」を作り、金床（かなとこ）で装備に付けます。

| エンチャント（日本語名） | 最大Lv | 付けられる対象 | 効果 |
|---|---|---|---|
| マナ再生 | 3 | 魔道防具 | 防具を着ている間、一定間隔でマナが自然回復（Lv1:+1／Lv2:+3／Lv3:+6） |
| マナ上昇 | 3 | 魔道防具 | 最大マナが増える（Lv1:+15／Lv2:+30／Lv3:+50） |
| 回生（そうるばうんど） | 1 | 耐久のある装備 | 装備が壊れる一撃を1回だけ肩代わり。エンチャントを消費して装備を完全修復（1回限り） |
| 共有（しぇあ） | 1 | スペルブック専用 | 組んだスペルを他の人にも詠唱させられる共有マーカー |

### 付け方（儀式→金床）
1. 儀式でエンチャント本を作る（回生の本は少し重い素材が必要）。
2. 金床で「装備＋エンチャント本」を合成して付与する。
3. 本は1個消費。合成のコストは回生だけ高め（他は軽い）。

補足:
- マナ再生・マナ上昇は「魔道防具にだけ」付きます。共有は「スペルブックにだけ」、回生は「耐久のある装備」に付きます。
- 回生が付いた装備は「本人のもの」として記録され、壊れる瞬間に一度だけ復活します。もう一度使いたい場合は、また儀式で本を作って付け直します。

## 節目レベルアップの全体アナウンス

**キリのよいレベル（既定は10の倍数）へ到達すると、サーバー全体へお知らせが流れます**（効果音付き）。誰かが軽量武器Lv30に到達すれば、その場にいなくても全員のチャットに表示されます。

- **総合（POWER）のレベルアップは、既定では告知されません。** 総合はほかのスキルのレベルアップから自動的に積み上がる値で、プレイヤーが直接稼ぐものではないためです。
- 1回のフラッシュで流れる行数には上限があり、超過分は静かに間引かれます。

## 自分の育成状況を確認する
`/trinityforge stats`（短縮形 `/tf stats`）で、自分の育成状況をまとめて確認できます（自分のぶんだけ・見るだけのコマンド）。

表示される内容:
- 戦闘レベル（上で説明した「上位スキルの柱」方式で算出）。
- スキルレベル（戦闘レベルに使う各スキルの現在レベル）。
- 今持っている武器の品質と、そこから導かれる攻撃ステータス。
- 装備している防具の合計ステータス（防御・厳選ぶんの合算）。

> このコマンドには、後述のプレステージ回数やロールは表示されません。プレステージは `/skills` の各ツリーから確認・実行します。

## プレステージ

プレステージは実装済みです。対象スキルが設定レベル（通常100）へ到達すると**ツリーの一番上**にプレステージノードが解放されます。

**1回目のクリックでは実行されません。チャットに確認が出るので、もう一度クリックすると確定します。**

> 確認のチャットには「プレステージ名・何回目か・パークが全部外れること・スキルポイントが返ること・ロックは維持されること・レベルの行き先」が出ます。以前は確認がアイコンの名前と説明文にしか出ておらず、しかもプレステージノードは幹の最上段＝**最初の表示位置の外**にあるため、「押しても何も起きない」ように見えていました（2026-08-21 に修正）。

- 対象スキルのレベル・EXPと通常Perkをリセットします。
- 使用済みポイントを返却し、プレステージ回数と永続ボーナスをまとめてサーバー側のデータに安全に保存します（保存中に他の操作が割り込んでも壊れない方式）。
- **総合（POWER）だけは 0 に戻りません。** 他のスキルから再計算される値なので、プレステージ後も改めて導出されます。**プレステージによる総合EXPの減衰も 0（＝減りません）**。つまり**スキルポイントは失われません**。
- **プレステージには回数の上限があり、ツリーごとに違います。** 武器3ツリー（軽量武器・重量武器・弓術）とArs魔法ツリーは3回まで、防具・生産系のツリーは5回まで実行できます。1回きりではありません。**総合（POWER）ツリーにはプレステージがありません。**
- ツリーごとの固有名と永続ボーナスの内容は、運営の設定で管理されています。

## ロール（職業）

ロール（戦闘職の剣闘士・魔術師・守衛、補助職の農家・漁師・鉱夫・土工・きこり）は実装済みです。

### 戦闘職の効果

| 職業 | 効果 |
|---|---|
| 剣闘士 | 物理ダメージが敵の防御率を **20%貫通**する |
| 魔術師 | 魔法ダメージに **30%の割合追加ダメージ**が乗る |
| 守衛 | 被ダメージを **10%軽減**し、ヘイト（敵の狙われやすさ）が **1.5倍**になる |

### 補助職の効果（5種）

| 職業 | 対応スキルのEXP倍率 | 常時効果 |
|---|---|---|
| 農家 | 農業 ×1.25 | Hero of the Village（村人との取引が有利） |
| 漁師 | 釣り ×1.35 | 幸運（Luck） |
| 鉱夫 | 採掘 ×1.15 | 採掘速度上昇（Haste） |
| 土工 | 切削 ×1.35 | 移動速度上昇（Speed） |
| きこり | 伐採 ×1.15 | 火炎耐性 |

補助職は倍率がそれぞれ異なる点に注意してください（一律ではありません）。倍率は「稼ぎやすさ」に反比例するように設定されており、待ち時間が支配的な釣り・土工は高め、単位時間の稼ぎが大きい採掘・伐採は控えめになっています。

### ロールの変更（有料化）

**ロールの転職は現在、有料です。**

- 各枠（戦闘職・補助職）への**初回の就職だけは無料**です。
- 2回目以降の転職には「**転職の証**」というアイテムが必要で、これを手に持って右クリックすると変更できます。
- **`/tf role clear`（ロールの解除）は塞がっています。** 枠を空にできてしまうと、初回無料枠を何度でも使い回せてしまうためです。
- 変更の動線は **`/tf status` のロールアイコンをクリックするか、転職の証を右クリックする方法のみ**です。**`/tf menu` と `/tf role set` コマンドは廃止**されています。

各ツリーのプレステージ内容は[スキルツリー詳細](14-スキルツリー詳細.md)、ロールの注意点は[実装状況と注意点](12-実装状況と注意点.md)を参照してください。

## つまずきやすいポイント（まとめ）
- 戦闘レベルは「スキルレベル」から決まり、良い装備を拾っても戦闘レベル自体は上がらない。ただし実際のダメージには装備ステも乗る。
- 戦闘レベルは「上位スキルの柱」方式（除数1.5/2/2.5/3）で実装済み。ただし各数値は調整中（暫定）。
- **軽量武器・重量武器・弓術ツリーのバフは、その武器種をメインハンドに持っているときだけ効く。** 複数ツリーを育てても、持ち替えれば恩恵は消える。
- グリフ・レシピの解放条件は、初期状態では設定が空のため全員が素通りで自由に使える。一方、装備そのものの使用レベル制限（近接・遠隔の武器）はすでに有効だが、**防具の装備と魔法触媒の詠唱のゲートは未実装**。
- 戦闘スキルのEXPはダンジョン内×0.375／外×0.1875（**内は外の2倍**）。モブ定義に無い敵（ハチ・イルカ等）は討伐EXPが0。
- EXPを削るしくみが3つある: **レベル差の足きり**（相手が15レベル以上格上だと減り30差で0。職業EXPは"その職業のレベル"で比べる）／**日次逓減**（24時間で10万EXPごとに×0.9・下限50%・発動から24時間で強制解除）／**同一地点の逓減**（半径16・5分で80体まで満額・下限40%・ダンジョン内は免除）。
- ダンジョンは**選んだ挑戦レベルが高いほど報酬が増える**（モブLv35が基準で、70以上ならドロップ×1.5・EXP×1.25）。
- プレステージは `/skills` のツリー上端にあるノードをクリック→**チャットに出る確認を読んでもう一度クリック**して実行する。**回数の上限があり、武器3ツリーとArs魔法は3回、防具・生産系は5回まで。総合にはプレステージが無い。**
- **プレステージしてもスキルポイントは減らない**（総合のEXPは減衰しない）。
- ロールの転職は初回無料・2回目以降は「転職の証」が必要な有料制。`/tf menu`と`/tf role set`は廃止され、動線は`/tf status`のロールアイコンか転職の証の右クリックのみ。

詳しい実装状況・矛盾点・今後の予定は、すべて[実装状況と注意点](12-実装状況と注意点.md)にまとめています。
