# 魔法のしくみ

## このページでわかること

- 呪文は「フォーム（形態）＋効果＋増強（オーグメント）」のグリフを並べて作る。先頭は必ずフォーム。
- グリフは「筆記台（ふでかきだい）」で解放し、ワンドや魔法書に呪文を保存して使う。
- マナ・クールダウン（CT）・増強のしくみと、魔法ダメージがどこで計算されるか。

> このページの数値は現在調整中（暫定）のものが多いです。今後のアップデートで変わることがあります。

---

## 1. 呪文はグリフを並べて作る

このサーバーの魔法（ArsPaper。Ars Nouveau風の魔法プラグイン）では、呪文を**グリフ（魔法文字）を一列に並べて**自分で組み立てます。決まった呪文を覚えるのではなく、「材料を並べてレシピを作る」感覚です。

グリフには3つの種類があります。

| 種類 | 日本語 | 役割 | 例 |
|---|---|---|---|
| フォーム | 形態 | 呪文を**どうやって放つか**（発動方法） | 弾を飛ばす、触れる、自分にかける |
| 効果 | エフェクト | 実際に**何が起きるか**（作用） | ダメージ、回復、ブロック破壊 |
| 増強 | オーグメント | 直前のフォームや効果を**強める・変える** | 威力アップ、範囲アップ、貫通 |

### いちばん大事なルール: 先頭は必ずフォーム

呪文の**一番左（先頭）には必ずフォームを1つ置きます**。フォームが無い呪文は「未完成」とみなされ、保存も発動もできません。フォームは呪文の中で1つだけです。

### 並べ方の例

```
[弾（projectile）] [ダメージ（harm）] [威力（amplify）] [範囲（aoe）] [回復（heal）] [延長（extend_time）]
```

この並びは「ダメージ（harm）に威力＋範囲、回復（heal）に延長」という意味になります。ルールはシンプルです。

- 先頭のフォームの後ろ、**最初の効果が出てくるまで**に置いた増強は「フォームを強める増強」になります（弾速アップや分裂など）。
- **効果の後ろ**に続く増強は、その直前の効果を強めます。

つまり「効果の直後にその効果を強める増強を置く」と覚えればOKです。

> 合計マナコストは、並べたグリフ全部のマナコストの単純な足し算です。長い呪文ほどたくさんマナを使います。

## 2. グリフの入手と呪文の保存

### グリフは「筆記台」で解放する

新しいグリフは、**筆記台（スクライビングテーブル。刻印台とも表示）** というブロックで解放します。

- 解放には **経験値レベル** と **素材** を支払います（グリフごとに必要量が違う）。
- 一度解放したグリフは、そのプレイヤーがずっと使えるようになります。
- どのグリフが何レベルで解放できるかは[呪文グリフ一覧](06-呪文グリフ一覧.md)の各表を見てください。

### 呪文は「魔法書」に保存する

作った呪文は、**魔法書（スペルブック）** に保存して使います。魔法書は**ティア（等級）が3段階**（初級・中級・上級）あり、上のティアほど高ティアのグリフを使え、保存できる呪文スロットも増えます（3／6／10スロット）。

| やりたいこと | 操作 |
|---|---|
| 呪文を発動する | 魔法書を持って右クリック（いま選んでいるスロットの呪文が出る） |
| 保存スロットを切り替える | スニーク＋右クリック |
| 作成画面を開く | スニーク＋左クリック（所有者のみ） |

- 魔法書は最初に持った人が「所有者」になります。所有者以外は発動はできますが、中身を編集する作成画面は開けません。
- さらに、魔法書に入れた呪文を**手持ちの別アイテム（触媒）にバインド**して撃つこともできます。焔の杖などの触媒は、魔法ダメージに会心・貫通を上乗せします。詳しいアイテムの入手・性能は[アイテム図鑑](04-アイテム図鑑.md)を見てください。

> 以前あった「スペルワンド」は廃止され、呪文を手持ちアイテムにバインドするしくみで置き換えられました。

## 3. スペル作成GUI（呪文づくりの画面）

呪文づくりの画面（スペル作成GUI）の開き方は、ワンドと魔法書で少し違います。

- **スペルワンド**: **スニーク＋右クリック**で開きます。
- **スペルブック（魔法書）**: **スニーク＋左クリック**で開きます（スニーク＋右クリックは後述の「スロット切替」になるので注意）。

### 画面の構成

| 場所 | 役割 |
|---|---|
| 上段 | いま組んでいる呪文の並び（最大9スロット） |
| 中段 | 使えるグリフの一覧（パレット）。フォーム／効果／増強のタブで切替 |
| 下段 | タブ切替ボタン、全消去（TNT）、設定、保存ボタン |

### 操作のポイント

- 操作は**すべてクリックだけ**で完結します。**統合版（Geyser）でもそのまま使えます**。
- **中段のパレット**でグリフをクリックすると、上段の呪文の並びに追加されます（増強・効果は空いているスロットの左から自動で入ります。フォームは常に一番左）。
- 外すときは、**上段（呪文の並び）側のグリフをクリック**します。何を外すかで消える範囲が変わります。
  - フォームを外す→ 呪文全体が空っぽに戻る
  - 効果を外す→ その効果より後ろの効果・増強がまとめて消える
  - 増強を外す→ その枠だけが空く（後ろは詰められない）
- **保存ボタンを押して初めて確定**します。ESC（閉じる）で閉じると変更は破棄されます。

### 追加できないときの理由

グリフによっては、その場で追加できないことがあります。主な理由は次の通りです。

| 表示・状況 | 意味 |
|---|---|
| 未解放（バリア表示） | まだ筆記台で解放していない。「筆記台で解放してください」 |
| ティアオーバー | そのグリフのティアが、使っているワンド／魔法書のティアより上（例: 上級グリフを初級ワンドに入れられない） |
| フォームの位置エラー | フォームは1つだけ、必ず先頭スロット |
| 効果の重複 | 同じ効果グリフは1つの呪文に1回まで |
| 増強の相性 | 直前のフォーム／効果と相性が合わない、または増強の付けられる個数（上限）を超えた |

- 増強がどのフォーム・効果に付けられるかは決まっています（相性＝互換性）。詳しくは[呪文グリフ一覧](06-呪文グリフ一覧.md)の各表の「付けられる増強」列を見てください。
- 画面には**呪文の合計マナコスト**が表示されるので、発動に必要なマナの目安になります。

> つまずきポイント: 「使用ゲート（perk＝許可証が要るグリフ）」というしくみもありますが、現在の設定では**すべてのグリフが誰でも自由に使えます**。将来、特定グリフに許可制が入る可能性があります（詳しくは[実装状況と注意点](12-実装状況と注意点.md)）。

## 4. マナ（魔力ゲージ）のしくみ

呪文を撃つにはマナ（魔法を使うためのエネルギー）が必要です。足りないと発動できません。

### 基本の数値

| 項目 | 値 | 意味 |
|---|---|---|
| 初期マナ上限 | 100 | 何もしていない状態の最大マナ |
| 回復間隔 | 20tick（＝1秒）ごと | この間隔で自動回復する |
| 1回の回復量 | 5 | 1秒ごとにマナが5戻る（初期値） |

> tick（ティック）＝ゲーム内時間の最小単位。20tick＝1秒です。

- 新しく参加したプレイヤーはマナ満タンで始まります。
- マナが現在の上限より減っていると、1秒ごとに自動で回復していきます。
- **呪文の合計マナコスト以上のマナが無いと発動できません**（発動前にチェックされ、足りなければ不発）。

### マナ上限・回復を増やす方法

マナの上限や回復速度は、いろいろな要素で伸ばせます。

| 増やす手段 | 効果 | 補足 |
|---|---|---|
| グリフを解放する | 解放1つごとにマナ上限＋5 | 育成が進むほど上限が伸びる |
| メイジ防具を着る | 装備部位ごとにマナ上限・回復が上がる | 系統で得意分野が違う（[アイテム図鑑](04-アイテム図鑑.md)） |
| スレッド（防具の付与）を付ける | 最大マナ＋20、回復＋2 など | 防具のスレッドスロットにセット |
| カスタムエンチャント | 「マナ上昇」で上限＋、「マナ再生」で回復＋ | 最大レベル3、金床で付与 |

- マナ上限を上げる要素は基本的に**足し算で重なります**（防具＋スレッド＋エンチャント＋グリフ解放分）。
- 詳しい装備・スレッド・エンチャントの数値は[アイテム図鑑](04-アイテム図鑑.md)にまとめてあります。

### 戦闘に連動したマナ回復（有効）

`config.yml` の `mana.recovery` が有効になり、戦闘の動きに応じてもマナが戻るようになりました（数値は暫定）。

| きっかけ | 回復量（最大マナに対する割合） |
|---|---|
| 被弾したとき | 最大マナの3% |
| 攻撃を当てたとき | 最大マナの3% |
| 戦闘していないとき（自然回復への上乗せ） | 最大マナの1% |

> 補足: ソースベリー（食べ物）を食べるとマナが即+100回復します。緊急時のマナ補給に便利です。

## 5. クールダウン（CT）＝連発を抑えるしくみ

呪文を撃つと、そのフォームに**クールダウン（CT。次に撃てるまでの待ち時間）** がかかります。

### CTの決まり方

| 項目 | 値 | 意味 |
|---|---|---|
| CTの単位 | プレイヤー × フォームごと | フォームが違えば別々にCTが進む |
| 既定のCT | 0.5秒（500ミリ秒） | 何もしなければこの長さ |
| CTの最短 | 0.1秒（100ミリ秒） | これ以上は短くならない |

- CTは「あなた × そのフォーム」の組み合わせごとに独立しています。たとえば「弾（projectile）」のCT中でも、別フォームの「自分（self）」の呪文はすぐ撃てます。
- **連射（rapid_fire）という増強**を**フォームの直後に途切れず並べる**と、1個ごとにCTが0.1秒ずつ短くなります（0.5秒→0.4秒→…→最短0.1秒）。フォームと連射の間に他の増強を挟むと、そこでカウントが止まります。
- ビーム（beam）フォームは連射を2個ぶん最初から内蔵しているので、標準でCTが短めです。

このしくみのおかげで、強力な呪文を一瞬で連発して敵を溶かす、というバースト（瞬間火力）が抑えられ、戦闘のバランスが保たれています。

> 現状、フォームごとのCT個別調整（config）はほとんど設定されておらず、ほぼ上の計算どおりに動きます（バランス調整中）。

## 6. 増強の「層分離」＝魔法とTFの役割分担

このサーバーの魔法は、土台プラグインである**TrinityForge（TF。ダメージ計算を一元管理する土台）** と役割を分担しています。ここが設計のキモです。

### だれが何を計算するか

| 計算すること | 担当 | 具体例 |
|---|---|---|
| 呪文の基礎ダメージ・範囲・持続の増減 | 魔法（ArsPaper）側 | 威力（amplify）で基礎ダメージを増やす、範囲（aoe）で当たる範囲を広げる |
| 会心・貫通・防御・耐性などの共通ダメージ計算 | TrinityForge（TF）側 | 最終的にどれだけ通るかの計算 |

つまり、**威力アップや範囲アップの増強は「魔法の内側」で先に計算**され、そこで出た基礎ダメージを**TFの共通計算（対称ダメージパイプライン）にそのまま渡す**のです。

### 魔法ダメージも共通の8ステップを通る

魔法で与えるダメージも、武器の物理ダメージとまったく同じ計算の流れ（8ステップ）を通ります。だから覚えることは戦闘ページと共通で済みます。

- 会心・貫通・防御率・耐性などは、武器攻撃と同じTFのルールで処理されます。
- 触媒（ワンド／魔法書）が持つ会心・貫通のステータスも、この共通計算に連携されるようになりました。触媒を厳選して会心・貫通を盛れば、魔法ダメージにもきちんと反映されます。
- 詳しい8ステップは[戦闘のしくみ](02-戦闘のしくみ.md)を見てください。

> 「威力（amplify）を積めば基礎ダメージが増える」→「増えた基礎ダメージを、相手の耐性・防御が同じルールで削る」。この二段構えだと覚えておけば十分です。

## 7. つまずきポイント（誤解しやすいところ）

プレイヤーが確実に誤解しやすい点だけ、ここで先に触れておきます。詳しくは[実装状況と注意点](12-実装状況と注意点.md)にまとめてあります。

- **触媒（ワンド／魔法書）の会心・貫通は、魔法ダメージに連携済みです。** 触媒を厳選して会心・貫通を盛れば、魔法ダメージにも反映されます（以前の未連携から改善済み）。
- **使用ゲート（グリフの許可制）は現状すべて空**で、全グリフが誰でも自由に使えます。将来、許可制が入る可能性があります。
- **wallフォームは廃止**され入手できません（かつて未登録だった flare・sense_magic・toss・reset は登録済みで入手可能）。詳細は[呪文グリフ一覧](06-呪文グリフ一覧.md)の注記を参照。
- **一部の効果は共通計算を通りません**（例: solar／lunarは防御無視、ignite／hex／explosionは別処理）。攻撃の性能を測るときの注意点です。

## 8. まとめ

- 呪文は「フォーム＋効果＋増強」のグリフを並べて作る。先頭は必ずフォーム。
- グリフは筆記台で経験値＋素材を払って解放し、ワンド／魔法書に保存して使う。
- マナは初期上限100・1秒ごとに回復。装備やエンチャントで上限・回復が伸びる。足りないと撃てない。
- CTはフォームごとに独立。既定0.5秒、連射で短縮。連発を抑えるしくみ。
- 威力・範囲の増減は魔法側、会心・貫通・防御はTF側。魔法ダメージも共通の8ステップを通る。
- 触媒の会心／貫通は連携済み、戦闘連動のマナ回復も有効。使用ゲートは空で全グリフ自由、という現状の注意点あり。
