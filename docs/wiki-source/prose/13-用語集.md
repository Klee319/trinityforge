# 用語集

## このページでわかること

- Wikiに出てくる、このサーバー独自の言葉や少しむずかしい言葉の意味
- 五十音・アルファベット順で引けます

わからない言葉が出てきたら、ここで探してください。

## 基本の言葉

| 言葉 | 意味 |
|---|---|
| **tick（ティック）** | ゲーム内の時間の最小単位。**20tick＝1秒**。「100tick」なら5秒。 |
| **PvE** | Player versus Environment。プレイヤーが環境（モンスター）と戦う協力型の遊び方。このサーバーはPvEで、**PvP（プレイヤー同士の戦い）はなし**。 |
| **クロスプレイ** | Java版と統合版（スマホ・スイッチ等）が同じサーバーで一緒に遊べること。Geyserという仕組みで実現。 |
| **MMO** | 大人数で遊ぶ大規模なオンラインRPGのこと。 |

## 4つのプラグイン

| 言葉 | 意味 |
|---|---|
| **TrinityForge（TF）** | このサーバーの土台となる自作プラグイン。ダメージ・ステータス・厳選・ヘイトなど「数字の真実」を一元管理する。 |
| **ArsPaper** | 魔法プラグイン。呪文・マナ・儀式・魔力（ソース）・魔道具を担当。Ars Nouveau という有名MODを参考にした自作版。 |
| **EliteMobs** | 強敵（エリート）とダンジョンのプラグイン。このサーバーではTF連携用に改造（フォーク）されている。 |
| **フォーク** | 既存のプラグインを改造した派生版のこと。このサーバーのEliteMobsとArsPaperは、TrinityForgeと連携するよう改造されている。 |

## 戦闘の言葉

| 言葉 | 意味 |
|---|---|
| **物理／魔法** | 攻撃の属性。武器で殴れば物理、杖や魔法書の呪文なら魔法。敵によって効きやすさが違う。 |
| **対称ダメージパイプライン** | 物理も魔法も同じ8ステップの計算を通す仕組み。属性が違っても公平に計算される。 |
| **combatレベル（戦闘レベル）** | プレイヤーの総合戦闘力を表す0〜100の数値。**装備ではなくスキルレベルで決まる**。ダンジョン入場や装備使用制限に使う。 |
| **会心（クリティカル）** | 一定確率でダメージが増える仕組み。近接は武器（厳選）の会心率で機能し、魔法も触媒ステの連携で機能する。 |
| **貫通** | 相手の「防御率」を無視する能力。ただし「耐性」は貫通できない。 |
| **防御率** | ダメージを割合で減らす防御ステータス。貫通で無視される。 |
| **耐性** | 物理・魔法それぞれのダメージを割合で減らす防御。貫通されない硬い守り。 |
| **防具強度** | 「会心で上乗せされた分」だけを減らす、会心軽減の割合。会心が発生していない通常のダメージには効かない。バニラ防具の頑丈さ（Toughness）も少しだけこの数値に取り込まれる。 |
| **守備力（物理守備力／魔法守備力）** | ダメージから一定量を引く防御。物理用と魔法用で別々の数値として管理される。「固定ダメージ」で相殺されることがある。 |
| **固定ダメージ** | 相手の守備力を貫通して通す一定ダメージ。守備力のない相手には効果が薄い。 |
| **出血（Bleed）** | 近接攻撃で一定確率で付く継続ダメージ。時間が経つごとに何回かダメージを受ける。 |
| **ヘイト（敵対度）** | モンスターが「誰を狙うか」を決める数値。たくさんダメージを与えた相手ほど狙われやすい。 |
| **装備非依存** | 戦闘力が装備の強さに直接左右されない、という設計方針。装備tier（格）を上げただけでは戦闘力（combatレベル）は上がらない。 |
| **三すくみ** | 物理・魔法・防御が互いにジャンケンのように補い合う関係。特定のビルド一強にならないための設計。 |

## ステータス・アイテムの言葉

| 言葉 | 意味 |
|---|---|
| **厳選** | 同じアイテムでも、品質とランダムな追加ステータス（味付け）でアタリ・ハズレが出る仕組み。 |
| **品質** | アイテムの出来。0（粗製）〜9（三神）の10段階。高いほど味付けが良く出やすい。 |
| **ロールシード** | 厳選のランダム値を決める種の数字。品質と合わせてアイテムの内部データに保存され、そこからステータスが毎回計算される。 |
| **味付けステータス** | アイテムに付くランダムな追加ステータスのこと。 |
| **素材tier（ティア）** | 素材の格。木＜石＜銅＜鉄＜ダイヤ＜ネザライト（金は別枠）。ベースの性能に影響。 |
| **ベイクしない（焼き付けない）** | ステータスを固定値としてアイテムに書き込まず、毎回テーブルから計算すること。設定を直せば既存装備も再調整される。 |
| **バインド** | アイテムの持ち主しばり。ソウルバインド（持ち主固定・取引不可）／取引可／所有者バインドの3種。※取引制限の強制は未実装。 |
| **使用レベル制限** | 強い装備を使うのに必要なスキルレベル。近接武器・遠隔武器・ツール・防具・魔法触媒をTF進行DBのスキルLvで判定する。 |
| **プレイヤー基礎ステータス** | 運営が全プレイヤーに一律で設定できる、ステータスの初期値。装備・スキル・バフの合算にもう1段追加される「土台」のようなもの。空欄にした項目はバニラ通り（加算なし）になる。 |
| **Lore（ロア）** | アイテムの説明文（マウスを乗せると出る文章）。ステータスがここに表示される。 |
| **隠しデータ** | アイテムやプレイヤーに直接は見えない形で保存されている、内部用のデータのこと。品質やロールシードなどはここに保存される。 |

## 魔法の言葉

| 言葉 | 意味 |
|---|---|
| **グリフ** | 呪文の部品。フォーム・効果・増強の3種類がある。 |
| **フォーム（形態）** | 呪文の「撃ち方」。まっすぐ飛ばす、触れる、自分に、範囲に、など。呪文の先頭には必ず1つ置く。 |
| **効果（エフェクト）** | 呪文が実際に起こす作用。ダメージ、回復、燃焼、召喚など。 |
| **増強（オーグメント）** | 直前のフォームや効果を強化する部品。威力アップ、範囲拡大、貫通、連射など。 |
| **超増強（Super）** | 通常の増強2個分の効果を持つ強力な増強。マナコストは4倍。 |
| **マナ** | 呪文を撃つのに必要な魔力ゲージ。時間とともに回復。上限は装備などで増える。 |
| **クールダウン（CT）** | 呪文を撃った後、次に撃てるまでの待ち時間。フォームごとに別々に管理される。 |
| **筆記台（スクライビングテーブル）** | グリフを解放（覚える）ためのブロック。経験値レベルと素材を払う。 |
| **触媒** | 呪文を放つ道具のこと。このサーバーではワンドやスペルブック。 |
| **儀式** | 儀式コアと台座（ペデスタル）に材料を並べ、ソースを消費して発動する特別なクラフト。 |
| **ソース（魔力）** | 儀式やソースネットワークで使う魔力資源。ソースジャーに貯める。 |
| **ソースリンク** | 燃料や食料などを入れてソースを生み出すブロック。5種類ある。 |
| **スレッド** | 魔道防具のスロットにセットして特殊効果を付ける糸。儀式で作る。 |

## 育成・進行の言葉

| 言葉 | 意味 |
|---|---|
| **スキルツリー** | TrinityForgeのレベル成長システム。武器・採取・生産などの職ごとにレベルが上がる。 |
| **perk（パーク）** | `/tf skills`でポイントを消費して得る特典・解放権。TF進行DBへ永続化される。 |
| **解放ゲート（使用ゲート）** | グリフや装備の「入手は自由、使うのにレベルが必要」という制限方式。 |
| **Ars魔法（魔法スキル）** | このサーバー独自の魔法スキル。呪文を使うと成長し、戦闘レベルの「魔法柱」になる。 |
| **Ars鍛冶（魔道具クラフトスキル）** | このサーバー独自の魔道具クラフトスキル。レベルが魔道具のクラフト品質を決める。 |
| **プレステージ（転生）** | レベルをリセットして永続ボーナスを得るやり込み要素。対象スキルLv到達後、`/skills`上端のノードを2回クリックして実行する。 |
| **ロール（役職）** | 戦闘職（剣闘士・魔術師・タンク）と補助職（斥候・農夫・採掘夫）の組み合わせ。獣使いは未実装。 |

## モブ・ダンジョンの言葉

| 言葉 | 意味 |
|---|---|
| **エリート** | EliteMobsの強化モンスター。レベルを持ち、良い報酬を落とす。 |
| **ダンジョンテーマ** | ダンジョン全体の耐性のクセ（物理に硬い／魔法に硬い／両方少し硬い）。 |
| **モブプロファイル** | モンスター1体1体の防御データ（耐性・守備力・回避など）。 |
| **インポート** | 管理者がEliteMobsのモブをTFの防御プロファイルに変換すること。 |
| **フェイルオープン** | 設定が空・条件未設定のとき「制限なしで通す」動作。例：ダンジョンゲートが空なら誰でも入れる。 |
| **ワールド脅威** | スポーン地点から遠いほどモブが強くなる仕組み（距離レベル）。 |
