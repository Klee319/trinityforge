# 戦闘のしくみ

## このページでわかること

- 攻撃が「物理」か「魔法」かは、**何で攻撃したか**（武器か呪文か）で決まる。
- どんな攻撃も同じ8ステップの計算（対称ダメージパイプライン）を通ってダメージが決まる。
- 攻める側・守る側のステータスが、それぞれどこで効くのか。

> このページの数値は現在調整中（暫定）のものが多いです。今後のアップデートで変わることがあります。

---

## 1. まず結論: 攻撃の属性は「攻撃源」で決まる

TrinityForge（このサーバーのダメージを一手に管理する土台プラグイン）では、攻撃は必ず**物理**か**魔法**のどちらかに分けられます。どちらになるかは、あなたが持っている道具ではなく「**何で攻撃したか**」で自動的に決まります。

| 攻撃の手段 | 属性 | 例 |
|---|---|---|
| 武器・道具での近接攻撃 | 物理 | 剣・斧・素手で殴る |
| 弓・トライデントなどの発射体 | 物理 | 矢を射る、トライデントを投げる |
| 触媒（ワンドや魔法書）で放つ呪文 | 魔法 | 呪文グリフを組んだ攻撃 |

> 補足: 呪文（触媒で放つ攻撃）は「魔法」ダメージとして、武器の物理ダメージと同じ8ステップの計算を通ります。魔法ダメージの結線は済んでおり、触媒（ワンド／魔法書）由来の会心・貫通も反映されます（詳しくは[魔法のしくみ](05-魔法のしくみ.md)）。

---

## 2. 「対称ダメージパイプライン」ってなに?

物理も魔法も、**まったく同じ計算の流れ**を通ってダメージが決まります。この「同じ流れ」のことを対称ダメージパイプラインと呼びます。

- 「対称」＝物理と魔法を差別しない、という意味。
- 計算のプログラム自体は攻撃が物理か魔法かを見ていません。
- 違うのは「入れる数字」（耐性の種類や係数）だけ。流れは共通です。

つまり、物理攻撃を強くするのも魔法攻撃を強くするのも、**同じルールで考えられる**ということです。覚えることが一つで済みます。

---

## 3. ダメージ計算の8ステップ

攻撃が当たってから最終ダメージが出るまで、決まった順番で処理が進みます。順番がとても大事です。

| 順番 | 名前 | この段でやること（やさしく） |
|---|---|---|
| 0 | 回避（かいひ） | 守る側が「よけた」かを最初に判定。よけたらダメージは0で終了 |
| 1 | 基礎ダメージ作り | もとのダメージに「固定追加」と「割合追加」を足す |
| 2 | 会心（クリティカル） | 会心が出たらダメージを上乗せ。守る側の**防具強度**があると、この上乗せ分だけ減らされる |
| 3 | 防御率 | 守る側の防御率で割引く。ただし**貫通で減らせる** |
| 4 | 耐性 | 守る側の耐性で割引く。こちらは**貫通できない** |
| 5 | 補正・被ダメ軽減 | 攻める側の補正で増やし、守る側の軽減で減らす |
| 6 | 守備力 | 決まった値をダメージから引き算する（物理・魔法べつべつ） |
| 7 | 最小クランプ | ダメージが下がりすぎても「最低ライン」で下げ止める |
| 8 | 固定ダメージ相殺 | 守備力で引かれた分を、固定ダメージが払い戻す |

計算の最後に残った数字が、実際に相手へ与えるダメージです。

### 各ステップをもう少しくわしく

- **Step0 回避**: 攻撃の一番はじめに1回だけ判定します。よけられたら、後の計算はぜんぶ飛ばしてダメージ0。
- **Step1 基礎作り**: 「もとのダメージ＋固定追加＋（もとのダメージ×割合追加）」。ここで攻撃の土台を作ります。
- **Step2 会心**: 会心が出ると「会心ダメージ」の分だけダメージが上乗せされます。ここで守る側の**防具強度**が働き、**上乗せされた分だけ**を割引きます（例: 防具強度40%なら、会心の上乗せ分が6割になる）。防具強度は「会心の上乗せ」だけに効き、通常ダメージには一切影響しません。会心の上乗せ量がマイナスになる（＝会心が回復になる）ことはありません。
- **Step3 防御率**: 相手の守りで割引。ここは**貫通が効く**ので、貫通が高いほど防御率を無視できます。
- **Step4 耐性**: 相手の守りで割引。ここは**貫通がまったく効きません**。硬い相手はここでしっかり守られます。
- **Step5 補正・軽減**: 攻める側の「ダメージ補正」は100%を基準にした endpoint（例: 80%→0.8〜1.0、120%→1.0〜1.2）の範囲を毎攻ランダムに掛けます。そのあと守る側の「被ダメージ軽減」で減らします。
- **Step6 守備力**: 割合ではなく「決まった数」を引き算します。小さいダメージほど痛手になります。守備力は**物理と魔法で別々**にあり、物理攻撃には物理守備力、魔法攻撃には魔法守備力が使われます。
- **Step7 最小クランプ**: 引き算しすぎて0や下がりすぎになっても、最低ダメージ（既定は1.0）で止めます。
- **Step8 固定ダメージ相殺**: Step6で守備力が実際に削った分だけ、攻める側の「固定ダメージ」が押し戻します。守備力を貫くための保証枠です。

> 式で見たい人へ（補足）: Step1 `base = 基礎 + 固定追加 + 基礎×割合追加` / Step2 `base ×= (1 + 会心ダメージ×(1-防具強度))` / Step3 `base ×= (1 - 防御率×(1-貫通))` / Step4 `base ×= (1 - 耐性)` / Step8 `払い戻し = max(0, min(固定ダメージ, 守備力で削られた量))`。まずは上の日本語の意味だけ分かればOKです。

## 4. 攻める側のステータス（どう効くか）

攻撃を強くするステータスです。かっこ内はどのステップで効くかです。

| ステータス | 何をするか | 効くステップ | ひとこと |
|---|---|---|---|
| 会心率 | 会心（クリティカル）が出る確率 | 0（判定） | 0だと絶対に会心しない |
| 会心ダメージ | 会心したときの上乗せ量 | 2 | 例: 0.5で+50% |
| 固定追加ダメージ | ダメージに決まった数を足す | 1 | 弱い攻撃ほど恩恵が大きい |
| 割合追加ダメージ | 基礎ダメージの割合で足す | 1 | もとが大きいほど効く |
| 貫通（かんつう） | 相手の防御率を無視する | 3 | 耐性には効かない |
| 固定ダメージ | 守備力の引き算を押し返す | 8 | 相手に守備力が無いと効果ゼロ |

> 会心について: 近接武器の会心は、武器（厳選）の会心率が判定に渡されて機能します。魔法（呪文）の会心も、触媒（ワンド／魔法書）由来の会心率が連携され機能します。会心率0のときだけ会心しません（詳しくは[実装状況と注意点](12-実装状況と注意点.md)）。

## 5. 守る側のステータス（どう守るか）

ダメージを減らすステータスです。かっこ内はどのステップで効くかです。

| ステータス | 何をするか | 効くステップ | ひとこと |
|---|---|---|---|
| 防御率 | 割合でダメージを減らす | 3 | 貫通で無効化されることがある |
| 耐性（物理・魔法別） | 割合でダメージを減らす | 4 | 貫通で減らせない。属性ごとに別々 |
| 被ダメージ軽減 | 割合でさらにダメージを減らす | 5 | 攻撃の種類を問わず効く |
| 守備力（物理・魔法別） | 決まった数を引き算する | 6 | 固定ダメージで相殺されることがある。物理と魔法で別々に持てる |
| 防具強度 | 会心の上乗せ分だけを減らす | 2 | 主に厳選・装備ステから作られる。通常ダメージには効かない（現行設定ではバニラの頑丈さからの変換は無効） |
| 回避 | 一定確率で攻撃をまるごと無効化 | 0 | よければダメージ0 |

補足: 耐性は「物理耐性」と「魔法耐性」が別々にあります。物理攻撃には物理耐性、魔法攻撃には魔法耐性が使われます。

## 6. 三すくみ（物理・魔法・防御）を壊さない設計

このサーバーは「攻めが強すぎて守りが無意味」「守りが硬すぎて攻めが通らない」にならないよう、3つの軸がじゃんけんのように釣り合う設計になっています。

| ルール | 意味 | どうバランスが保たれるか |
|---|---|---|
| 耐性は貫通できない | Step4の耐性は貫通が一切効かない | 守り（耐性）を積んだ相手には貫通ゲーが通じない |
| 防御率は貫通できる | Step3の防御率は貫通で無視できる | 攻め（貫通）を積めば硬い相手も削れる |
| 守備力は固定ダメージで相殺できる | Step6で引かれた分をStep8が押し返す | 固定の守りと固定の攻めが打ち消し合う |

つまり、「一つのステータスを積めば全部解決」にはなりません。相手に合わせて攻め方を変えるのがこのサーバーの戦闘の面白さです。

### 大事な安全装置

| 安全装置 | 値 | 意味 |
|---|---|---|
| 割合軽減の上限 | 90% | 防御率・耐性・被ダメージ軽減は、**それぞれ**最大90%までしか効かない。1つの守りだけで完全には防げない |
| 最小ダメージ | 1.0 | どれだけ守りを固めても、当たれば最低このダメージは必ず通る（下げ止まり） |

割合の軽減は「それぞれ最大90%まで」なので、複数を重ねれば通るダメージはかなり小さくできます。ですが最後に**最小ダメージ**の下げ止まりがあるため、どんなに硬い相手でも「完全に無敵」にはなりません。必ずダメージを与える道が残ります。

> ここで大事なのは「1つの守りだけで完封はできない」ことです。耐性は貫通されませんが、それ単体では最大90%まで。守りには必ず穴があります。

## 7. 出血（Bleed）

近接攻撃には、一定確率で相手を出血させる仕組みがあります。出血はじわじわとダメージが続く効果（DoT）です。

| 項目 | 内容 |
|---|---|
| 発動する攻撃 | 近接攻撃のみ（弓や呪文では出ない） |
| 発動条件 | 武器が「出血確率」と「出血ダメージ」を両方持っているとき、確率で発動 |
| ダメージの間隔 | 20tick（＝1秒）ごと（既定） |
| 続く回数 | 5回（＝既定で約5秒間） |
| ダメージの流れ | 出血の各回も通常のダメージ計算を通る（相手の防御が1回分効く） |
| 重ねがけ | 同じ相手には出血1個まで。もう一度当てても、加算ではなく**時間がリセット**される |

> 注意: 出血のダメージは相手のHPへ直接書き込まれる方式のため、ノックバックや被弾モーション、トーテムなどの一部の挙動と噛み合わない可能性があります。挙動の細かい検証は今後の課題です（詳しくは[実装状況と注意点](12-実装状況と注意点.md)）。

## 8. 強さの土台は「戦闘レベル」＋装備ステ

このサーバーのダメージは、**戦闘レベル（combatレベル）による成長**と、**装備に載るステータス（攻撃力など）**の両方が効きます。

- 戦闘レベルは、戦闘スキルツリーのレベルから計算されます（[育成と解放](08-育成と解放.md)）。
- レベルが1上がるごとに、基礎ダメージが少しずつ伸びます（既定はレベルあたり **+1%**）。
- あわせて、武器などの `attack-power`（攻撃力）や会心・貫通といった装備ステも基礎ダメージや各ステップに乗ります。品質による厳選は、この装備ステの上振れに効きます。

| 項目 | 内容 |
|---|---|
| 戦闘レベルの決まり方 | 対象スキル（軽量武器・重量武器・弓術・Ars魔法）のうち「伸びている上位スキル」から算出（[育成と解放](08-育成と解放.md)で詳説） |
| レベル成長 | 戦闘レベル（装備の品質とは別枠） |
| レベルあたりの伸び | +1%（既定・調整中） |
| 装備の役割 | 攻撃力・会心・貫通などのステを載せる（厳選で個体差が出る） |
| レベルの範囲 | 0〜100（既定） |

つまり「スキルを育てつつ、良い個体の装備を厳選する」のが強さの両輪です。育成の詳しい話は[育成と解放](08-育成と解放.md)を見てください。

## 9. まとめ

- 攻撃の属性は攻撃源で決まる（武器＝物理、呪文＝魔法）。
- 物理も魔法も同じ8ステップを通る（対称ダメージパイプライン）。
- 貫通は防御率に効き、耐性には効かない。守備力は固定ダメージで相殺できる。これが三すくみの土台。
- 軽減は最大90%まで。最低1割は必ず通る。
- ダメージは戦闘レベル成長（既定+1%/Lv）と装備ステ（攻撃力など）の両方で決まる。
- 会心は近接武器の会心率で機能し、魔法ダメージも触媒ステが連携済み。各機能の現状は[実装状況と注意点](12-実装状況と注意点.md)を参照。
