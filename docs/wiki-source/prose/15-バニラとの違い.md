# バニラとの違い

いつものマインクラフトと**ルールが変わっているところだけ**を集めたページです。
知らないまま遊ぶと「壊れている」と誤解しやすい所を先に置いています。

> 遊びはじめる手順そのものは [はじめかた](00-はじめかた.md) にあります。

---

## まず知っておく5つ

| これは | こう変わっている |
|---|---|
| **修繕（Mending）** | **このサーバーには存在しません。** 拾っても釣っても出ません |
| **エンチャント台** | 提示レベルもコストも**一律 7 割**。本棚を満タンにしてもバニラの Lv30 相当は出ません |
| **連打** | 連打すると1発の威力が**最大 10 分の 1 まで**落ちます。振り切ってから当てるのが基本 |
| **PvP** | **事実上できません**（ダメージは **0.001 倍**、1発の上限は相手の最大体力の 25%） |
| **品質** | 同じ名前の装備でも品質 **0〜15 の 16 段階**＋ランダム補正で性能が変わります |

## エンチャント

### 修繕は無くなっています

修繕（Mending）はサーバー側で取り除かれています。宝箱・モブのドロップ・釣り・村人との取引・拾ったアイテム・ホッパー経由、どの経路から入っても消えます。ログイン時の持ち物とエンダーチェストも掃除されます。

代わりに **木材修繕** があります。金床に「圧縮木材」と一緒に入れると耐久が回復します。伐採のスキルツリーで解放してください。

### エンチャント台の効きが弱くなっています

本棚の効果が **0.7 倍** になっています。

- 提示されるエンチャントのレベルが下がります（例：ダメージ増加 V → IV）
- 必要な経験値レベルも同じ割合で下がります
- 本棚を 15 個そろえても、バニラの Lv30 相当にはなりません

**弱体化した代わりに、スキルツリーでバニラの上限を超えられます。**

### バニラ上限を超えるエンチャント

エンチャントのスキルツリーで、**武力・防力・知力の 3 路線のうち 1 つ**を選んで解放します（Lv60 → Lv80）。3 つは排他なので、全部は取れません。

| エンチャント | 上限 |
|---|---|
| ダメージ増加／射撃ダメージ増加／密度 | 6 → **7** |
| 各種防護 | 5 → **6** |
| 効率強化 | 6 → **7** |
| 幸運／ドロップ増加／宝釣り | **5** |
| 耐久力／水中歩行／棘の鎧 | **5** |
| 召雷 | **6** |

> 上限を超えられるのはこの表に載っているエンチャントだけです。それ以外はバニラどおりです。

### そのほか

- **不適正なツールにはエンチャントが付きません。** 金床で無理やり付けようとしても弾かれます（エンチャント本そのものは例外）。
- **釣り上げたエンチャント本の中身が違います。** バニラは複数の効果がまとめて付きますが、ここでは **1 種類だけがランダムなレベルで**付きます。呪いと修繕は出ません。
- **砥石でエンチャントを外しても、装備の品質とステータスはそのままです。** 外して付け直しても「当たり」は引き直せません。

## 採掘・伐採などの採集

### 採掘速度は「効率強化」として動く

このサーバーの採掘速度ボーナスは、**持っている採取ツールに効率強化エンチャントとして自動で書き込まれます**。

- 持ち替える、持ち物を開く、死ぬ、ログアウトする → **いったん外れます**（戻すと付き直します）
- 金床を開いている間はツールチップから消えます

**これは不具合ではありません。** 統合版（スマホ・Switch など）でも同じ挙動になるようにするための作りです。

### 追加のしくみ

| しくみ | 内容 |
|---|---|
| 鉱脈掘り | つながった鉱石をまとめて掘ります（採掘ツリーで解放） |
| 一括伐採 | 木を根元から丸ごと倒します（伐採ツリーで解放） |
| 高速破壊 | しゃがみながら右クリックで一時的に採掘が速くなります |
| 解体 | 金床で装備を「スクラップ」に戻せます（鍛冶ツリーで解放） |

オン／オフは `/tf settings` で切り替えられます。

## 戦闘

### 連打しても強くなりません

**攻撃をためている途中で振ると、威力が最大 10 分の 1 まで落ちます。** バニラと同じく、クールダウンが戻ってから振ってください。重い武器ほどこの差が大きく出ます。

さらに、**攻撃を受けた側には 0.5 秒の無敵時間**があります。攻撃速度をいくら積んでも、実際に通るのは **1 秒あたり 2 発**までです。

### 守備力は「引き算」です

防具の守備力は割合ではなく、**受けたダメージからそのまま引かれます**。しかも会心の判定より前に引かれます。

- **弱い攻撃には非常に強く、大きな一撃には弱い**という性質になります
- 一部の攻撃（固定ダメージ）は守備力を**完全に無視**します

### 効かないものがあります

**出血・毒・ウィザーの継続ダメージは、「被ダメージ軽減」以外の防御を一切通りません。** 回避も守備力も耐性も無視されます。継続ダメージ対策は別枠だと考えてください。

### 敵も魔法を使います

一部の敵は攻撃の一部または全部が**魔法ダメージ**です。物理耐性だけを積んでいると通ります。

| ほぼ全部が魔法 | 魔女、エヴォーカー、イリュージョナー |
|---|---|
| 大半が魔法（9割） | エルダーガーディアン、ガーディアン、ガスト、ウィザー |
| 7〜8割が魔法 | ブレイズ、シュルカー、ブリーズ、エンダードラゴン |
| 半分〜6割が魔法 | ウォーデン、ヴェックス、クリーキング |
| 3〜4割が魔法 | ストレイ、ボグド、ウィザースケルトン |

**ストレイ・ボグド・ウィザースケルトンのように「見た目はただのスケルトン」でも4割前後が魔法**です。
物理守備力だけを積んでいると、この帯で急に削られはじめます。魔法成分を持つのは全部で17種です。

### ダンジョンは「敵の攻撃属性」と「通る武器」が別々です

**2026-08-21 に「魔法で殴ってくる敵には必ず物理が通る」というルールは廃止されました。**
現在は「魔法で殴ってきて、魔法が通る」ダンジョンも普通にあります。
**敵の攻撃属性を見ただけで持つ武器を決めないでください。** 詳しくは[モブとダンジョン](09-モブとダンジョン.md)を参照。

### 場所で敵の強さが決まります

- 初期スポーン地点から**離れるほど**敵のレベルが上がります
- **ネザーは最低でも Lv50 相当から**始まります
- **エンドは最低でも Lv80 相当から**始まります
- エンダードラゴンは **Lv100**

準備なしにネザーへ行くと、地上の感覚では戦えません。

### そのほか

- **日光で燃えるダメージは最大体力の 10%** です。体力を増やしても軽くなりません。
- **反射（棘の鎧の系統）は「一定の確率で、自分の素手のダメージを返す」方式**です。受けたダメージに比例しません。
- **ダンジョンの中では装備の耐久が余分に減ります。** 被弾するたび、そして死んだときに減ります。ただし**壊れることはありません**。
- **PvP は事実上できません。** 有効ではありますが、プレイヤーへのダメージは **0.001 倍**（1000分の1）まで下げてあり、1 発の上限も相手の最大体力の 25% です。

## アイテム

| これは | こう変わっている |
|---|---|
| 品質 | **0〜15 の 16 段階**（劣悪 … 神器・三神・不滅・幻想・未踏・特異点） |
| ステータスの上限 | **ありません**。積んだ分だけ効きます |
| 経験値の保存 | エンチャントの瓶を作るのではなく、**ガラス瓶を右クリック**して溜めます。取り出すと必ず目減りします |
| カスタムの食べ物 | **満腹度が設定されていないものは食べられません**（素材として使います） |
| アイテムのクールダウン | 見た目が同じ品どうしでクールダウンを共有します |
| スレッド（糸） | 装備の**スレッド枠**に挿す強化パーツがあります。**持っているだけでは効きません**。着ている防具はスニーク＋右クリック、手持ちの武器・道具は `/ars thread` で挿します（枠は0〜4、儀式で最大5まで拡張可） |

## 村人との取引

**司書・武器鍛冶・防具鍛冶・道具鍛冶の 4 職は、スキルツリーで解放するまで取引画面すら開きません。**

- 武器鍛冶・防具鍛冶・道具鍛冶 → **鍛冶 Lv90** で解放
- 司書 → **エンチャント Lv90** で解放

解放したあとは、このサーバー専用の取引が使えます。

> **司書からエンチャント本を買う遊び方はできません。** 解放しても取引が 0 件です。エンチャント本は釣り・儀式・宝箱から手に入れてください。

## ワールドと構造物

### 資源サーバーのワールドは毎週作り直されます

このサーバーは **メイン／資源／開発の 3 台**で動いています。

- **資源サーバーのワールドは毎週月曜の 4:00 に丸ごと新品へ戻ります。** 掘り尽くしても翌週には元通りです
- **資源サーバーに拠点を作らないでください。** 建てたものは毎週消えます
- **メインのワールドは作り直されません。** 拠点はこちらへ

### サーバー間で引き継がれるもの

| 引き継がれる | 引き継がれない |
|---|---|
| 持ち物、経験値、スキル、図鑑、実績 | `home` の登録場所 |

チャットは全サーバーへ流れます（発言に `【メイン】` のようなサーバー名が付きます）。ただし**誰もいないサーバーへは届きません**。

**ダンジョンはメインサーバーだけにあります。**

### 構造物の中身が変わっています

- 生成される構造物の**宝箱の中身は、ほぼすべて入れ替えてあります**。地形と構造物を増やすデータパックが入っており、そこで増えた構造物の宝箱も対象です
- **貧相な宝箱ほど、入っている個数が多くなる**ように調整されています（探して損をしにくくするため）
- **データパックが独自に追加するエンチャント本は取り除かれます。** このサーバーのエンチャント体系と合わないためです
- 村・トライアルチャンバー・壺や発掘の宝箱は**手を加えていません**（バニラのままです）

### リソースパックは必須です

追加アイテムの見た目に必要なので、参加時にリソースパックの適用を求められます。

## 育成まわり

| しくみ | 内容 |
|---|---|
| **AFK** | 5 分で放置とみなされ、スキル経験値・バニラ経験値・モブのドロップ・釣りの換金が止まります。30 分で切断されます。**クリックと腕振りは「動いている」に数えません** |
| **稼ぎすぎの逓減** | 同じスキルで 10 万経験値を稼ぐごとに獲得量が 0.9 倍ずつ落ちます（**下限 50%**）。**発動から 24 時間で必ず 100% へ戻ります** |
| **同じ場所での狩り** | 半径 16 ブロック・直近 5 分で **80 体までは満額**、それを超えると1体ごとに 2% ずつ落ちます（下限 40%）。**ダンジョンの中では起きません** |
| **ダンジョンの外** | 戦闘系スキルの経験値は**ダンジョン内の半分**です（内 ×0.375 / 外 ×0.1875）。戦って伸ばすならダンジョンへ |
| **定義の無い敵** | ハチ・イルカ・ヤギ・ゴーレム・オオカミなどは**討伐しても経験値が入りません**。繁殖でスキルは伸びません |
| **レベル差の足きり** | 倒した相手が自分より**大きく高レベル**だと、経験値とドロップが削られます。職業経験値は**その職業のレベル**を基準に、15 レベル差から絞られ 30 レベル差で 0。ドロップは 20 レベル差で止まります。パーティで連れて行ってもらっても免除されません |
| **バニラの進捗** | 表示されません。代わりに `/tf achievement` の実績があります |
| **役割（ロール）の変更** | **最初の 1 回だけ無料。** そのあとは「転職の証」が要ります |
| **節目のレベルアップ** | 10 の倍数のレベルに到達すると、全サーバーへお知らせが流れます |
