# モブとダンジョン

## このページでわかること

- このサーバーのモブは「遠くにいるほど強い」設計で、ダンジョンには**鍵アイテムによる入場制限**があります。
- ダンジョンの3層構成の考え方、鍵の入手方法、ダンジョンごとの難易度・物理/魔法のコンセプト、モブの特殊攻撃、フィールド限定ドロップ、ダンジョン内の耐久ペナルティなどをまとめます。
- 未実装の部分（ペット連携など）や、注意すべき点も正直に書きます。

---

## ダンジョンの3層構成（考え方）

このサーバーの冒険は、ざっくり3つの層でイメージすると分かりやすいです。

| 層 | 呼び方 | イメージ |
|---|---|---|
| 1層 | 常設フィールド | いつでも入れる普通の世界。街の外に広がる冒険エリア。 |
| 2層 | 反復ダンジョン | 何度でも挑めるダンジョン。腕試しや稼ぎの場。 |
| 3層 | エンドコンテンツ | このサーバーの最終目標となる最高難易度ダンジョン。 |

> 大事な注意: この「3層」はあくまで**遊び方を整理するための考え方（概念）**です。TrinityForge（このサーバーの土台プラグイン）には「これは何層目のダンジョン」と区別するしくみは実装されていません。実際にどのダンジョンがどの層かは、EliteMobs（強敵とダンジョンのプラグイン）側のコンテンツの作り方で決まります。TrinityForgeは、その上に「鍵ゲート」「難易度」「モブの防御」「ヘイト」といった機能を横断的に足しているだけです。

## モブは「遠いほど強い」（ワールドの脅威）

このサーバーのモブは、**スタート地点から遠く離れるほどレベルが上がり、強くなる**設計思想になっています。

- 近くの安全地帯では弱いモブ、遠くの奥地では強いモブ。
- 「遠くに行く」＝「危険が増える」＝「報酬も大きくなる」という、冒険らしい緊張感を作るための考え方です。
- つまり、無理に遠出する前に、まず自分の戦闘力（combatレベル）を育てておくことが大切です。

> combatレベル（戦闘力）は装備の強さではなく、スキルツリーのレベルで決まります。詳しくは[育成と解放](08-育成と解放.md)を参照してください。

> この「遠いほど強い」は、**フィールドに湧く通常モブ**の話です。ダンジョンに取り込まれたEliteMobsの強敵（エリートモブ）は、取り込み時の設定でレベルが決まります（EliteMobs側で設定されたレベルをそのまま使うか、管理者が指定した固定レベルを使うか、のどちらか）。距離でレベルが変わるのはフィールドの通常モブだけです。

### フィールドモブと装備帯の対応（目安）

主要敵対モブ（ゾンビ系・スケルトン系・スパイダー・クリーパー・エンダーマン・ウィッチなど）の HP / 攻撃力は、`stats/item-stats.yml` の武器 `attack-power` と `use-level-requirement` をアンカーに合わせています（設定: `combat/mob-types.yml`）。

| 目安 | 内容 |
|---|---|
| 距離係数 | 約 **500ブロックで +10レベル**（`coordinate-coefficient: 0.02`） |
| 体感（標準） | **同帯のライト武器で約6ヒット**、同帯の軽〜中防具ならモブ攻撃を **約12〜20ヒット**耐えられる想定 |
| 主戦場 | use-lv **0〜40**（木〜金）。Lv55以降のフィールドはエンド装備より柔らかめ（高難易度の本命はダンジョン） |

役割の差（例: スパイダーはガラス寄り、エンダーマンは硬め）は、同じカーブに倍率を掛けた個別登録です。動物など未登録Entityは `defaults` の軽い既定のままです。

### ネザー・エンドは最初から強い

ネザーとジ・エンドは、フィールドの「距離で強くなる」計算とは別に、**次元ごとの最低レベル**が設定されています（`combat/mob-types.yml`）。

| 次元 | 最低レベル |
|---|---|
| ネザー | Lv50 |
| ジ・エンド | Lv80 |

- エンダードラゴンは基準レベル60ですが、上の次元最低レベルと全モブ共通の上限（`max-level: 100`）に挟まれ、実質**Lv100**として扱われます。
- 「軽い気持ちでネザーに行ったら瞬殺された」を避けるため、ネザー・エンド行きは事前に戦闘力を上げてから。

### モブも魔法で攻撃してくる

一部のモブは、通常攻撃の一部（または全部）が**魔法ダメージ**として計算されます（`combat/mob-types.yml` の `magic-ratio`）。物理防具だけを固めていると、これらのモブには思ったより効かせにくくなります。

| 割合 | 該当モブ |
|---|---|
| 1.0（完全魔法） | 魔女・エヴォーカー・イリュージョナー |
| 0.9 | エルダーガーディアン・ガスト・ガーディアン・ウィザー |
| 0.8 | ブレイズ・シュルカー |
| 0.7 | ブリーズ・エンダードラゴン |
| 0.6 | ウォーデン |

> 純粋な近接モブ（ゾンビ・スケルトン・スパイダー・クリーパー・ピグリンなど）は完全物理のままです。全敵対モブのうち、魔法成分を持つのは上記の17種だけです。

### 手懐けたモブは飼い主とともに強くなる

テイム済みモブ（オオカミなど）は、**飼い主の総合戦闘レベル**に応じて強くなります（`combat/mob-types.yml` の `tamed:` 設定）。放置していた使い魔も、育成が進めば自然と頼れる存在になります。

## ダンジョンの鍵（入場制限）

**現在、全28ダンジョンすべてが「鍵アイテムを1個消費して入る」場所です。** 鍵を持っていないと入場できません（`dungeon/gates.yml`）。

- **鍵アイテム消費**: 対応する鍵アイテムを1個持っていないと入れず、入場時にそのアイテムが消費されます。
- **戦闘レベル要求**: ほとんどのダンジョンにはレベル制限がありません。**「世界を繋ぐ者の聖所」（最終ダンジョン）だけが Lv40 以上を要求**します。

### 鍵アイテムを右クリックすると潜入確認画面が開く

鍵アイテムを右クリックすると、**潜入確認GUI**が開きます。「潜入する」を選ぶと、そのダンジョンへ転送されます（`listeners/DungeonKeyItemListener.java`）。誤って鍵を消費してしまうことはありません。

### 鍵の入手は2系統

| 入手方法 | 対象 | 補足 |
|---|---|---|
| クラフト | 17種 | ワークベンチでレシピどおりに揃えれば作れます（`items/catalog.yml`） |
| 構造物チェスト | 11種 | 探索で発見する構造物のチェストから低確率で出ます |

構造物チェストの出現率は、チェストのランク（豪華さ）によって次のように分かれます。

| ランク | 出現率 |
|---|---|
| T5（最上位クラス） | 約2% |
| T4 | 約1.8% |
| T3 | 約1.5% |

> 「なかなか出ない」と感じたら、豪華な構造物（要塞・砦・古代都市など格上のチェスト）を優先して探すと、体感の出現率が上がります。

### 最終ダンジョンの鍵だけは特別

最終ダンジョン「世界を繋ぐ者の聖所」の鍵は、他の鍵と違って**ダンジョン踏破の証（ダンジョンの印）を集めて作る**という特殊なクラフトです。

- **ダンジョンの印 5個 ＋ 深淵の合金 2個 ＋ 現実の芯 1個**でクラフトできます。
- 印は**28種類あるダンジョンの印のうち、どれでも構いません**。5個集まれば作れます。
- つまり、いろいろなダンジョンを踏破して回るほど、最終ダンジョンへの近道になります。

### エンチャント試練は1本道

「エンチャント試練」は1〜10の**一本道**の連続ダンジョンです。試練1の鍵がないと試練2には挑めず、飛び級はできません。

- 各試練の踏破ボスを倒すと、**次の試練の鍵が確実（確率100%）にドロップ**します（`combat/mob-overrides.yml`）。
- つまり、試練1の鍵さえ手に入れば（クラフトで作れます）、あとは踏破していくだけで10まで進めます。

## ダンジョンの難易度と、物理/魔法のコンセプト

### 難易度1〜10

ダンジョンには、モブの攻撃力倍率（`attack-power-multiplier`）にもとづく**難易度1〜10**が割り振られています。数値が大きいほど、モブの攻撃が重くなります。

| 難易度 | 攻撃力倍率 | 該当ダンジョン（例） |
|---|---|---|
| 1（最も易しい） | 2.3 | 闇の大聖堂 |
| 2 | 2.5 | ハロウィン闘技場、深層鉱山 |
| 3 | 2.7 | 古橋の聖所、騎士団の城 |
| 4 | 2.9 | 宮殿、蒸気機関工房 |
| 5 | 3.2 | 鉱山、ネザーの鐘 |
| 6 | 3.4 | 花火工房、ドワーフの地下都市、ネザーの荒野 |
| 7 | 3.7 | 北極ミニダンジョン、下水道迷宮 |
| 8 | 4.1 | 登攀路、採石場 |
| 9 | 4.4 | 灼熱の洞窟 |
| 10（最も厳しい） | 4.8 | 世界を繋ぐ者の聖所 |

### 物理/魔法のコンセプト

ダンジョンごとに、モブの攻撃の何割が魔法かを示す `magic-ratio` が設定されています。この割合から、そのダンジョンで有利な攻め方が読み取れます。

| コンセプト | 意味 | 該当ダンジョン数 |
|---|---|---|
| 魔法推奨（magic-ratio 0.10） | 敵の攻撃はほぼ物理。物理装甲が厚いので、**魔法が通りやすい** | 12本 |
| 物理推奨（magic-ratio 0.45） | 敵の攻撃は魔法寄り。魔法防御が厚いので、**物理武器が通りやすい** | 11本 |
| 両対応（magic-ratio 0.25） | 物理・魔法どちらの装備でも戦える中庸型 | 5本 |

> **エンチャント試練は奇数=物理推奨・偶数=魔法推奨の交互**になっています（試練1・3・5・7・9が物理推奨、試練2・4・6・8・10が魔法推奨）。1〜10を通しで踏破するには、**1本の装備だけでは登り切れません**。物理・魔法の両方を育てておくか、試練ごとに装備を持ち替える必要があります。

## モブの特殊攻撃

ダンジョン内のモブ90体に、15種類の特殊攻撃（`combat/mob-abilities.yml`）が配線されています。ただ殴り合うだけでなく、「読んで避ける」動きが必要になる技です。

| 技名 | タイプ | 特徴 |
|---|---|---|
| 震脚 | 全方位攻撃 | 自分の足元を中心にダメージ＋ノックバック |
| 足砕き | 全方位攻撃 | ダメージは軽いが鈍足が乗る |
| 矢の雨 | 遠距離 | 頭上から矢が降ってくる（その場に立っていると複数本当たる） |
| 火の粉 | 遠距離 | 扇状に火球を撃つ（魔法ダメージ） |
| 突進 | 突進 | 対象へ突進し着地時に周囲へダメージ |
| 影渡り | 瞬間移動攻撃 | 対象の背後へ転移して斬りつける |
| 枯死の霧 | 継続範囲 | 弱化を伴う継続ダメージ域を展開 |
| 凍気 | 継続範囲 | 鈍足を伴う継続ダメージ域を展開 |
| 貫通光 | 直線攻撃 | 遮蔽物がないと避けられない高倍率ビーム（倍率2.0） |
| 招集 | 召喚 | ゾンビを呼ぶ |
| 群れを呼ぶ | 召喚 | エンダーマイトを呼ぶ |
| 烈風叩き | 全方位吹き飛ばし | ダメージは控えめだが、強い吹き飛ばしで位置を崩す |
| 深淵の手 | 引き寄せ | 半径16m以内のプレイヤーを引き寄せる。遮蔽物が効かない |
| 星降りの徴 | 予告設置 | 1.6秒の予告後に着弾する高倍率技。見てから避けられる |
| 地烈の棘 | 予告設置 | 着弾すると打ち上げられる |

一部のバニラの強敵にも、上の特殊攻撃が付与されています（`combat/mob-overrides.yml`）。

| ピリジャー | 矢の雨 |
| ウィッチ | 凍気 |

## フィールド限定のドロップ

### モブ固有の討伐素材16種

特定のモブを**フィールドで**倒すと、そのモブ専用の素材が低確率でドロップします（`combat/mob-level-table.yml`）。ダンジョン内のモブからは出ません。

- ラヴェジャーの革、ピグリンブルートの鎧片、ピリジャーの鎧片、ウィッチの秘薬、ピグリンの耳、ストレイの布片、スケルトンホースの骨、エンダーマイトの煤、ガーディアン/エルダーガーディアンの棘、ハスクの布片、ボグドの苔むした骨、ホグリンの牙、砂まみれの骨、エルダーガーディアンの棘、ウィザーの頭蓋骨、ウォーデンの触覚
- 確率は**Lv1で5%からLv100で50%まで連続的に上がる**補間式です。倒すモブのレベルが高いほど出やすくなります。
- 別枠でエンダードラゴンの鱗（100%固定・0〜2個）もあります。

### スレッド5種

特定のモブをフィールドで倒すと、まれに専用の「スレッド」も落ちます（Lv1で1%→Lv100で10%）。

| スレッド | 対象モブ |
|---|---|
| 昏倒のスレッド | ヴィンディケーター |
| 射手のスレッド | スケルトン |
| 浮遊のスレッド | シュルカー |
| 詠唱効率のスレッド | エヴォーカー |
| 速攻のスレッド | 子どものゾンビ限定 |

## 複数人ダンジョンの追加ドロップ

複数人でダンジョンに潜っているとき、TrinityForgeが追加する特別なドロップ（討伐素材など）は、**地面に直接落ちず、EliteMobsの共有戦利品テーブル（need/greed）に載ります**。60秒の受付時間を経て、参加者の中から1人が当選します（`mobs/EliteMobsSharedLootBridge.java`）。

- 引き取り条件は、**エリートモブであること・ダメージ寄与者が2人以上いること・そのうち誰かがインスタンス化ダンジョンの中にいること**です。
- **ソロで潜っているときや、フィールドでの共闘では、従来どおり地面にそのまま落ちます。**（need/greedの対象になるのは複数人ダンジョンだけ）

---

## ダンジョン内では装備の耐久が余分に減る

ダンジョン内で戦っていると、通常のダメージ計算とは別に、装備の耐久値が追加で減っていきます（`combat/damage.yml`）。

| タイミング | 減少量 |
|---|---|
| 被弾するたび | 最大耐久値の0.1%（オフハンドも含む） |
| 死亡したとき | 最大耐久値の10%（両手に持っていた装備も含む） |

> **`prevent-break: true` なので、この耐久ペナルティで装備が壊れることはありません。** あくまで「ダンジョンに潜ると装備が消耗する」という体験のための仕組みで、修理の手間が増えるだけです。この耐久ペナルティは**ダンジョン内限定**で、フィールドでは発生しません。

---

## 討伐EXPのルール

- **EliteMobsで定義されていないモブ（モブ定義に無いモブ）は、討伐EXPが0**です（`stats/skill-exp.yml`）。
- **ダンジョンの外（フィールド）での戦闘スキルEXPは、ダンジョン内の×0.25**に抑えられています。フィールド狩りだけで戦闘スキルを伸ばそうとすると、ダンジョンに潜るより効率が悪くなります。

---

## ダンジョンはメインサーバー限定

ダンジョン関連のプラグイン（EliteMobs）は、資源サーバーには導入されていません（`ops/PLUGIN_MATRIX.md`）。**ダンジョンに挑めるのはメインサーバーだけ**です。資源サーバーは採取に特化した構成になっています。

## ダンジョンテーマ（ダンジョン全体の耐性のクセ）

ダンジョンには「**テーマ**」を設定でき、テーマはそのダンジョン全体のモブが持つ**耐性のクセ（どの攻撃に硬いか）**を決めます。テーマは3種類あります。

まず、攻撃には2種類あることを思い出してください。

- **物理**: 武器で殴る攻撃。
- **魔法**: 触媒（ワンドや魔法書）で放つ呪文の攻撃。

（詳しくは[戦闘のしくみ](02-戦闘のしくみ.md)を参照）

### 3つのテーマと、攻略のヒント

| テーマ | どんなクセか | 有利な攻め方 |
|---|---|---|
| physical_fortress（物理要塞） | 近接（物理）に硬く、魔法には柔らかい | **魔法ビルドが有利** |
| arcane_ward（魔法防壁） | 魔法に硬く、近接（物理）には柔らかい | **物理ビルドが有利** |
| balanced（バランス型） | 物理・魔法どちらにも軽く硬い | どちらでも戦えるが、決定打には欠ける |

### テーマの数値（参考）

テーマの防御はモブのレベルに応じて伸びていきます。数値は「基本値 ＋ 1レベルごとの増分」で表され、レベルが上がるほど強くなります。守備の成分は「防御率・耐性・被ダメ軽減・守備力（固定値）」の4つです。

#### physical_fortress（物理要塞）

| 成分 | 防御率 | 耐性 | 被ダメ軽減 | 守備力（固定） |
|---|---|---|---|---|
| 物理 | 0.10 ＋ 0.004/Lv | 0.05 ＋ 0.002/Lv | 0 | 1.0 ＋ 0.2/Lv |
| 魔法 | 0 | 0 | 0 | 0 |
| 防具強度（共通） | — | — | — | 0 ＋ 0.1/Lv |

物理防御だけを固めているので、魔法で攻めると素通りしやすいダンジョンです。

#### arcane_ward（魔法防壁）

| 成分 | 防御率 | 耐性 | 被ダメ軽減 | 守備力（固定） |
|---|---|---|---|---|
| 物理 | 0 | 0 | 0 | 0 |
| 魔法 | 0.10 ＋ 0.004/Lv | 0.05 ＋ 0.002/Lv | 0 | 1.0 ＋ 0.2/Lv |
| 防具強度（共通） | — | — | — | 0 |

魔法防御だけを固めているので、武器で殴るのが有効なダンジョンです。

#### balanced（バランス型）

| 成分 | 防御率 | 耐性 | 被ダメ軽減 | 守備力（固定） |
|---|---|---|---|---|
| 物理 | 0.05 ＋ 0.002/Lv | 0 | 0 | 0.5 ＋ 0.1/Lv |
| 魔法 | 0.05 ＋ 0.002/Lv | 0 | 0 | 0.5 ＋ 0.1/Lv |
| 防具強度（共通） | — | — | — | 0 ＋ 0.05/Lv |

両方に薄く硬いので、極端な弱点はありません。装備の得意な方で挑みましょう。

> 数値は現在調整中（暫定）です。今後バランス調整で変わる可能性があります。

## モブの防御プロファイル（2層のしくみ）

モブの硬さ（防御）は、**2層**で決まります。

1. **大枠（ダンジョンテーマ）**: 上のテーマが、そのダンジョンのモブ全体の防御の土台を作ります。
2. **モブ個別（逆張りの例外）**: 個別のモブだけ、テーマとは違う防御を持たせることもできます（管理者が手作業で設定した場合）。

各モブが持てる防御の成分は次のとおりです。物理・魔法それぞれに設定できます。

| 成分 | 意味（ざっくり） |
|---|---|
| 防御率 | 受けるダメージを割合で減らす |
| 耐性 | ダメージをさらに割合で減らす |
| 被ダメ軽減 | 受けるダメージを軽くする |
| 守備力（固定） | ダメージを固定量だけ減らす |
| 防具強度（共通） | 物理・魔法で共通の1つの値 |
| 回避 | 攻撃を確率でかわす（物理・魔法共通） |

> 大事なポイント: **防御プロファイルを持たないモブは、バニラ（通常のMinecraft）と同じ扱い**で、上の防御はすべて0です。ダンジョン用に作られたモブだけが、テーマや個別の防御を持ちます。
>
> 割合で減らす成分（防御率・耐性・防具強度＝会心軽減率）は、レベルで伸びても**0〜100%の範囲に必ず収まる**ように計算されています（マイナスになったり100%を超えたりしません）。

## EliteMobsのインポート（管理者向けの概要）

このサーバーでは、EliteMobsの強敵（エリートモブ）を、TrinityForgeの防御プロファイルに**変換して取り込む**しくみがあります。

- 管理者が `/trinityforge importmobs` コマンドを使うと、EliteMobsのモブ設定を読み取り、上で説明した「物理・魔法の防御」を持つTrinityForge流のモブに変換します。
- テーマを指定して取り込むと、そのダンジョンのモブ全体にテーマの耐性が付きます。

プレイヤーが直接使う機能ではありません。詳しい手順や注意点は[管理者ガイド-導入とコマンド](10-管理者ガイド-導入とコマンド.md)を参照してください。

## ヘイト（敵対度）システム

モブは、**自分に一番ダメージを与えた相手**を狙う傾向があります。この「狙われやすさ」を数値で表したものが**ヘイト（敵対度）**です。

- ヘイトは、与えたダメージの量に比例してたまります（現状は倍率1.0、つまりダメージ量そのままが蓄積）。
- たくさん殴った人ほどヘイトが高くなり、モブに狙われやすくなります。

> ヘイトの統一（改善済み）: 以前はTrinityForge本体側とEliteMobsフォーク側でヘイトが別々に二重実装されていましたが、**フォーク側がTrinityForgeの `HateService` に狙いの判定を委譲するよう統一**されました。TrinityForgeが動いている間は記録も判定もTrinityForge側の1つの帳簿だけで行われ、フォーク独自の簡易テーブルは**TrinityForgeが居ないとき・読み取りに失敗したときだけ**の予備として使われます（同じ被弾が二重に計上されることはありません）。
>
> 現状の注意: タンク役は与ダメージ由来のヘイトが1.5倍になりますが、挑発・固定化・被ダメージ由来のヘイト、獣使いやペットによる操作は**未実装**です。詳しくは[実装状況と注意点](12-実装状況と注意点.md)を参照してください。

## このサーバーでの「EliteMobsの変わっている点」

このサーバーのEliteMobsは改造版です。普通のEliteMobsとくらべて、プレイヤー目線で次のように変わっています。

| 項目 | 普通のEliteMobs | このサーバー |
|---|---|---|
| 与えるダメージ | 装備の強さで倍率がかかる | **装備倍率は無効**。ダメージ計算はTrinityForgeに一本化 |
| 戦闘力（combatレベル） | EliteMobs独自の計算（武器＋防具の平均） | **TrinityForg基準**（スキルツリーのレベル）に差し替え |
| 装備の修繕 | 金床・砥石・修繕エンチャントで直せる | **修繕は廃止**（エリート装備は直せない） |
| 所有者バインド | EliteMobs独自 | TrinityForgeの**ソウルバインド**と連携（所有者を記録） |
| ドロップ品質 | EliteMobs任せ | ドロップに**厳選スタンプ**（品質と味付け）が付く |

> ドロップの品質（厳選）は、基本的に**倒した敵が強いほど良い品質が出やすく**なるように決まります（強い敵ほど良い品質のあたりに寄せて抽選されます）。敵の強さが分からないときや一部の設定では、どの品質も同じ確率になります。厳選のしくみそのものは[ステータスと厳選](03-ステータスと厳選.md)を参照してください。

## 重大な注意（かんたんまとめ）

次の点は、遊ぶうえで誤解しやすいので、簡潔に触れておきます。詳しくは[実装状況と注意点](12-実装状況と注意点.md)を参照してください。

- **全28ダンジョンが鍵アイテム必須**。レベル制限があるのは最終ダンジョン「世界を繋ぐ者の聖所」（Lv40）だけ。
- **鍵は右クリックで潜入確認GUIが開く**（誤消費の心配なし）。入手はクラフト17種＋構造物チェスト11種（T5約2%／T4約1.8%／T3約1.5%）。
- **エンチャント試練は1→10の一本道**。奇数=物理推奨・偶数=魔法推奨が交互で、1本の装備では登り切れない。
- **ヘイトはTFの `HateService` に統一済み**（TF不在時・読み取り失敗時のみフォーク側フォールバック）で二重計上はない。タンクは与ダメージ由来ヘイト1.5倍、獣使い/ペット操作と挑発は未実装。
- **ペット連携は未実装**。
- **ダンジョン内は装備耐久が余分に減るが、`prevent-break: true` なので壊れない。**
- **ダンジョンはメインサーバー限定**（資源サーバーにはEliteMobsが入っていない）。
- **ドロップ品質は「敵が強いほど良い品質が出やすい」抽選**（敵の強さが分からない場合や一部設定のときだけ、どの品質も同じ確率になる）。
