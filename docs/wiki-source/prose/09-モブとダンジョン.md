# モブとダンジョン

## このページでわかること

- このサーバーのモブは「遠くにいるほど強い」設計で、ダンジョンには入場条件やダンジョンごとの「耐性のクセ」があります。
- ダンジョンの3層構成の考え方、入場ゲート、ダンジョンテーマ、モブの防御、ヘイト（狙われやすさ）のしくみを、やさしくまとめます。
- 未実装の部分（ペット連携など）や、注意すべき点も正直に書きます。

---

## ダンジョンの3層構成（考え方）

このサーバーの冒険は、ざっくり3つの層でイメージすると分かりやすいです。

| 層 | 呼び方 | イメージ |
|---|---|---|
| 1層 | 常設フィールド | いつでも入れる普通の世界。街の外に広がる冒険エリア。 |
| 2層 | 反復ダンジョン | 何度でも挑めるダンジョン。腕試しや稼ぎの場。 |
| 3層 | エンドコンテンツ | このサーバーの最終目標となる最高難易度ダンジョン。 |

> 大事な注意: この「3層」はあくまで**遊び方を整理するための考え方（概念）**です。TrinityForge（このサーバーの土台プラグイン）には「これは何層目のダンジョン」と区別するしくみは実装されていません。実際にどのダンジョンがどの層かは、EliteMobs（強敵とダンジョンのプラグイン）側のコンテンツの作り方で決まります。TrinityForgeは、その上に「入場ゲート」「テーマ」「モブの防御」「ヘイト」といった機能を横断的に足しているだけです。

---

## モブは「遠いほど強い」（ワールドの脅威）

このサーバーのモブは、**スタート地点から遠く離れるほどレベルが上がり、強くなる**設計思想になっています。

- 近くの安全地帯では弱いモブ、遠くの奥地では強いモブ。
- 「遠くに行く」＝「危険が増える」＝「報酬も大きくなる」という、冒険らしい緊張感を作るための考え方です。
- つまり、無理に遠出する前に、まず自分の戦闘力（combatレベル）を育てておくことが大切です。

> combatレベル（戦闘力）は装備の強さではなく、スキルツリーのレベルで決まります。詳しくは[育成と解放](08-育成と解放.md)を参照してください。

> この「遠いほど強い」は、**フィールドに湧く通常モブ**の話です。ダンジョンに取り込まれたEliteMobsの強敵（エリートモブ）は、取り込み時の設定でレベルが決まります（EliteMobs側で設定されたレベルをそのまま使うか、管理者が指定した固定レベルを使うか、のどちらか）。距離でレベルが変わるのはフィールドの通常モブだけです。

### フィールドモブと装備帯の対応（目安）

主要敵対モブ（ゾンビ系・スケルトン系・スパイダー・クリーパー・エンダーマン・ウィッチなど）の HP / 攻撃力は、`stats/item-stats.yml` の武器 `attack-power` と `use-level-requirement` をアンカーに合わせています（設定: `combat/mob-types.yml`）。

| 目安 | 内容 |
|---|---|
| 距離係数 | 約 **500ブロックで +10レベル**（`coordinate-coefficient: 0.02`） |
| 体感（標準） | **同帯のライト武器で約6ヒット**、同帯の軽〜中防具ならモブ攻撃を **約12〜20ヒット**耐えられる想定 |
| 主戦場 | use-lv **0〜40**（木〜金）。Lv55以降のフィールドはエンド装備より柔らかめ（高難易度の本命はダンジョン） |

役割の差（例: スパイダーはガラス寄り、エンダーマンは硬め）は、同じカーブに倍率を掛けた個別登録です。動物など未登録Entityは `defaults` の軽い既定のままです。

## ダンジョン入場ゲート（入場制限）

一部のダンジョンには「**入場ゲート**」があり、条件を満たさないと入れません。条件は主に次の2つです。

- **combatレベル要求**: 決められた戦闘力に達していないと、入口ではじかれます。
- **鍵アイテム消費**（設定されている場合のみ）: 指定のアイテムを持っていないと入れず、入場時にそのアイテムが消費されます。

はじかれると、赤いメッセージで理由（レベル不足、または鍵不足）が表示されます。

### ゲートの判定は1つのしくみに統一されている

入場ゲートは、行き先の種類に応じて「何をキーに見るか」が違うだけで、**判定・鍵の消費はすべて同じ1つのしくみ**（`dungeon/gates.yml`）で行われます。

- **別ワールドへのテレポート**: 行き先の**ワールド名**でゲートを判定します。
- **同じワールド内の区画（region）ダンジョン**: 設定された**区画定義**への出入りでゲートを判定します（境界をまたぐたび）。
- **EliteMobsのダンジョン（インスタンス）に参加するとき**: 専用ワールドが作られる前の時点で、そのダンジョンの**内部名**でゲートを判定します。

どちらの入り口でも、combatレベル要求と鍵アイテムの消費は同じルールで働きます（「EliteMobs側は鍵が要らない」といった違いはありません）。

> 区画（region）タイプのゲートは、**歩いて境界をまたぐたびに毎回判定され、鍵が設定されていれば毎回消費されます**。ワールドを出入りするたびに鍵を用意する必要がある、という点に注意してください。

> 現状の重要な注意: **ゲートは、初期設定では中身が空っぽ＝「誰でも入れる」状態**です。条件を満たしていなくても素通りできます（このように「設定がなければ通す」ことを fail-open といいます）。入場制限を効かせるには、管理者が `dungeon/gates.yml` に設定を書き込む必要があります。詳しくは[実装状況と注意点](12-実装状況と注意点.md)も参照してください。

## ダンジョンテーマ（ダンジョン全体の耐性のクセ）

ダンジョンには「**テーマ**」を設定でき、テーマはそのダンジョン全体のモブが持つ**耐性のクセ（どの攻撃に硬いか）**を決めます。テーマは3種類あります。

まず、攻撃には2種類あることを思い出してください。

- **物理**: 武器で殴る攻撃。
- **魔法**: 触媒（ワンドや魔法書）で放つ呪文の攻撃。

（詳しくは[戦闘のしくみ](02-戦闘のしくみ.md)を参照）

### 3つのテーマと、攻略のヒント

| テーマ | どんなクセか | 有利な攻め方 |
|---|---|---|
| physical_fortress（物理要塞） | 近接（物理）に硬く、魔法には柔らかい | **魔法ビルドが有利** |
| arcane_ward（魔法防壁） | 魔法に硬く、近接（物理）には柔らかい | **物理ビルドが有利** |
| balanced（バランス型） | 物理・魔法どちらにも軽く硬い | どちらでも戦えるが、決定打には欠ける |

### テーマの数値（参考）

テーマの防御はモブのレベルに応じて伸びていきます。数値は「基本値 ＋ 1レベルごとの増分」で表され、レベルが上がるほど強くなります。守備の成分は「防御率・耐性・被ダメ軽減・守備力（固定値）」の4つです。

#### physical_fortress（物理要塞）

| 成分 | 防御率 | 耐性 | 被ダメ軽減 | 守備力（固定） |
|---|---|---|---|---|
| 物理 | 0.10 ＋ 0.004/Lv | 0.05 ＋ 0.002/Lv | 0 | 1.0 ＋ 0.2/Lv |
| 魔法 | 0 | 0 | 0 | 0 |
| 防具強度（共通） | — | — | — | 0 ＋ 0.1/Lv |

物理防御だけを固めているので、魔法で攻めると素通りしやすいダンジョンです。

#### arcane_ward（魔法防壁）

| 成分 | 防御率 | 耐性 | 被ダメ軽減 | 守備力（固定） |
|---|---|---|---|---|
| 物理 | 0 | 0 | 0 | 0 |
| 魔法 | 0.10 ＋ 0.004/Lv | 0.05 ＋ 0.002/Lv | 0 | 1.0 ＋ 0.2/Lv |
| 防具強度（共通） | — | — | — | 0 |

魔法防御だけを固めているので、武器で殴るのが有効なダンジョンです。

#### balanced（バランス型）

| 成分 | 防御率 | 耐性 | 被ダメ軽減 | 守備力（固定） |
|---|---|---|---|---|
| 物理 | 0.05 ＋ 0.002/Lv | 0 | 0 | 0.5 ＋ 0.1/Lv |
| 魔法 | 0.05 ＋ 0.002/Lv | 0 | 0 | 0.5 ＋ 0.1/Lv |
| 防具強度（共通） | — | — | — | 0 ＋ 0.05/Lv |

両方に薄く硬いので、極端な弱点はありません。装備の得意な方で挑みましょう。

> 数値は現在調整中（暫定）です。今後バランス調整で変わる可能性があります。

## モブの防御プロファイル（2層のしくみ）

モブの硬さ（防御）は、**2層**で決まります。

1. **大枠（ダンジョンテーマ）**: 上のテーマが、そのダンジョンのモブ全体の防御の土台を作ります。
2. **モブ個別（逆張りの例外）**: 個別のモブだけ、テーマとは違う防御を持たせることもできます（管理者が手作業で設定した場合）。

各モブが持てる防御の成分は次のとおりです。物理・魔法それぞれに設定できます。

| 成分 | 意味（ざっくり） |
|---|---|
| 防御率 | 受けるダメージを割合で減らす |
| 耐性 | ダメージをさらに割合で減らす |
| 被ダメ軽減 | 受けるダメージを軽くする |
| 守備力（固定） | ダメージを固定量だけ減らす |
| 防具強度（共通） | 物理・魔法で共通の1つの値 |
| 回避 | 攻撃を確率でかわす（物理・魔法共通） |

> 大事なポイント: **防御プロファイルを持たないモブは、バニラ（通常のMinecraft）と同じ扱い**で、上の防御はすべて0です。ダンジョン用に作られたモブだけが、テーマや個別の防御を持ちます。
>
> 割合で減らす成分（防御率・耐性・防具強度＝会心軽減率）は、レベルで伸びても**0〜100%の範囲に必ず収まる**ように計算されています（マイナスになったり100%を超えたりしません）。

## EliteMobsのインポート（管理者向けの概要）

このサーバーでは、EliteMobsの強敵（エリートモブ）を、TrinityForgeの防御プロファイルに**変換して取り込む**しくみがあります。

- 管理者が `/trinityforge importmobs` コマンドを使うと、EliteMobsのモブ設定を読み取り、上で説明した「物理・魔法の防御」を持つTrinityForge流のモブに変換します。
- テーマを指定して取り込むと、そのダンジョンのモブ全体にテーマの耐性が付きます。

プレイヤーが直接使う機能ではありません。詳しい手順や注意点は[管理者ガイド-導入とコマンド](10-管理者ガイド-導入とコマンド.md)を参照してください。

## ヘイト（敵対度）システム

モブは、**自分に一番ダメージを与えた相手**を狙う傾向があります。この「狙われやすさ」を数値で表したものが**ヘイト（敵対度）**です。

- ヘイトは、与えたダメージの量に比例してたまります（現状は倍率1.0、つまりダメージ量そのままが蓄積）。
- たくさん殴った人ほどヘイトが高くなり、モブに狙われやすくなります。

> ヘイトの統一（改善済み）: 以前はTrinityForge本体側とEliteMobsフォーク側でヘイトが別々に二重実装されていましたが、**フォーク側がTrinityForgeの `HateService` に狙いの判定を委譲するよう統一**されました。TrinityForgeが動いている間は記録も判定もTrinityForge側の1つの帳簿だけで行われ、フォーク独自の簡易テーブルは**TrinityForgeが居ないとき・読み取りに失敗したときだけ**の予備として使われます（同じ被弾が二重に計上されることはありません）。
>
> 現状の注意: タンク役は与ダメージ由来のヘイトが1.5倍になりますが、挑発・固定化・被ダメージ由来のヘイト、獣使いやペットによる操作は**未実装**です。詳しくは[実装状況と注意点](12-実装状況と注意点.md)を参照してください。

## このサーバーでの「EliteMobsの変わっている点」

このサーバーのEliteMobsは改造版です。普通のEliteMobsとくらべて、プレイヤー目線で次のように変わっています。

| 項目 | 普通のEliteMobs | このサーバー |
|---|---|---|
| 与えるダメージ | 装備の強さで倍率がかかる | **装備倍率は無効**。ダメージ計算はTrinityForgeに一本化 |
| 戦闘力（combatレベル） | EliteMobs独自の計算（武器＋防具の平均） | **TrinityForg基準**（スキルツリーのレベル）に差し替え |
| 装備の修繕 | 金床・砥石・修繕エンチャントで直せる | **修繕は廃止**（エリート装備は直せない） |
| 所有者バインド | EliteMobs独自 | TrinityForgeの**ソウルバインド**と連携（所有者を記録） |
| ドロップ品質 | EliteMobs任せ | ドロップに**厳選スタンプ**（品質と味付け）が付く |

> ドロップの品質（厳選）は、基本的に**倒した敵が強いほど良い品質が出やすく**なるように決まります（強い敵ほど良い品質のあたりに寄せて抽選されます）。敵の強さが分からないときや一部の設定では、どの品質も同じ確率になります。厳選のしくみそのものは[ステータスと厳選](03-ステータスと厳選.md)を参照してください。

## ペット連携について

ペットにダメージ属性を持たせたり、ペットがヘイトに参加したり、ペットのダメージを調整する、といった**ペット連携は現在すべて未実装**です。仕様の構想はありますが、実際に動くコードはありません。

---

## 重大な注意（かんたんまとめ）

次の点は、遊ぶうえで誤解しやすいので、簡潔に触れておきます。詳しくは[実装状況と注意点](12-実装状況と注意点.md)を参照してください。

- **入場ゲートは初期状態では素通り**（fail-open）。制限は管理者の設定待ち。
- **入場ゲートの判定・鍵の消費は1つのしくみに統一**されている（ワールド名／区画／EliteMobs内部名のどれをキーにするかが違うだけ）。区画タイプは境界をまたぐたびに毎回判定・消費される点に注意。
- **ヘイトはTFの `HateService` に統一済み**（TF不在時・読み取り失敗時のみフォーク側フォールバック）で二重計上はない。タンクは与ダメージ由来ヘイト1.5倍、獣使い/ペット操作と挑発は未実装。
- **ペット連携は未実装**。
- **ドロップ品質は「敵が強いほど良い品質が出やすい」抽選**（敵の強さが分からない場合や一部設定のときだけ、どの品質も同じ確率になる）。
