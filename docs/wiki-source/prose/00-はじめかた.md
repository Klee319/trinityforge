# はじめかた

はじめてログインした人が、**最初の30分で何をすればいいか**だけを書いたページです。
細かい理屈はあとから読めば大丈夫なので、まずはここに書いてある順にやってみてください。

---

## いちばん大事なこと（先に3つだけ）

1. **バニラのマインクラフトと同じように始められます。** 木を殴って、道具を作って、拠点を建てる。その流れは何も変わりません。
2. **ただし「戦闘」と「装備の強さ」のルールが違います。** 良い装備を拾っただけでは強くなりません。**スキルを上げた分だけ強くなります。**
3. **PvP（プレイヤー同士の戦い）はありません。** みんなで強敵に挑む協力型です。他の人を敵だと思わなくて大丈夫です。

Java版でも統合版（スマホ・Switch など）でも、同じワールドで一緒に遊べます。

---

## 手順1：スキルの画面を開いてみる（1分）

チャット欄に次のどちらかを打ちます。

```
skills
```

`/tf skills` でも同じ画面が開きます。

ここに **16種類のスキル（職業）** が並んでいます。採掘・伐採・農業・釣り・鍛冶・弓術・重武器……といった具合です。
**今は何も選ばなくて構いません。** 「こういう画面がある」とだけ覚えておいてください。

> **スキルは選ぶものではありません。やった行動のスキルが勝手に伸びます。** 木を切れば伐採が、鉱石を掘れば採掘が上がります。16種類すべてを同時に育てられるので、「職業選びを間違える」ということはありません。

> これとは別に **役割（ロール）** という仕組みがあります。こちらは1つだけ選ぶもので、**最初の1回は自由に選べますが、あとから変えるには「転職の証」が必要**です。選ぶのは `/tf status` の画面からです。急ぐ必要はないので、遊び方が固まってから決めてください。

---

## 手順2：ふつうに遊び始める（10〜20分）

やることはバニラと同じです。

- 木を切る → **伐採** が上がる
- 石や鉱石を掘る → **採掘** が上がる
- 土や砂を掘る → **掘削** が上がる
- 畑を作って収穫する → **農業** が上がる
- 釣りをする → **釣り** が上がる
- 敵と戦う → 使った武器の種類に応じたスキルが上がる

**最初のうちは「好きなことを1つ」に絞るのがおすすめです。** スキルは伸ばした分だけ新しい効果が解放されるので、あちこち少しずつより、1つを深く伸ばしたほうが早く変化を感じられます。

レベルが上がると、チャットに通知が出ます。区切りのいいレベルではサーバー全体にお知らせが流れます。

---

## 手順3：解放した効果を受け取る（レベルが上がったら）

`skills` の画面でスキルを選ぶと、**スキルツリー**が開きます。
レベルアップでもらえるポイントを使って、ツリーの上のマス（ノード）を解放していきます。

解放できるものの例：

- 採掘の**鉱脈掘り**（つながった鉱石をまとめて掘る）
- 伐採の**一括伐採**（木を根元から丸ごと倒す）
- 新しいアイテムの**作り方**
- 攻撃力や体力などの**常時上昇**

> **注意：ポイントは巻き戻せると思わないでください。** 何に振るか迷ったら、まず「鉱脈掘り」「一括伐採」のような**遊びが楽になるもの**から取るのが無難です。

---

## 手順4：自分の今の強さを見る（1分）

```
/tf status
```

自分の能力と役割が画面で確認できます。文字で見たいときは `/tf stats` です。

ここに出てくる数字が、実際の戦闘で使われている値です。
**装備を持ち替えると数字が変わります。** どの装備が本当に強いのかは、見た目やバニラの攻撃力ではなく、この画面で比べてください。

---

## 手順5：戦いに行く前に3つだけ知っておく

### ① 攻撃には「物理」と「魔法」がある

- **武器（剣・斧・弓など）で殴る → 物理**
- **杖や魔法書で呪文を撃つ → 魔法**

敵には「物理が効きにくいもの」「魔法が効きにくいもの」がいます。
**片方だけで苦戦したら、もう片方に持ち替えてください。** これが分かっていないと「急に敵が固くなった」と感じます。

### ② 遠くへ行くほど敵が強い

モンスターは、初期スポーン地点から**離れるほどレベルが上がります**。
強い場所には強い報酬がありますが、いきなり遠出すると勝てません。少しずつ広げてください。

### ③ 同じ装備でも当たり外れがある

装備には**品質**と**ランダムな追加ステータス**が付きます。同じ「鉄の剣」でも、当たりを引けばかなり強い1本になります。
これを **厳選** と呼びます。序盤は気にしなくて大丈夫ですが、「同じ名前なのに性能が違う」のは仕様です。

## 覚えておくと便利なコマンド

| 入力 | できること |
|---|---|
| `skills` または `/tf skills` | 職業とスキルツリーの画面を開く |
| `/tf status` | 自分の能力と役割を画面で見る（役割の変更もここから） |
| `/tf stats` | 自分に働いている能力を文字で見る |
| `/tf collection` | 図鑑（コレクション）の進み具合を見る |
| `/tf settings` | 演出のオン／オフ、鉱脈掘り・一括伐採などの挙動を切り替える |
| `/tf role` | 今の役割とその効果を文字で確認する |

## つまずきやすいところ

| こうなったら | 理由 |
|---|---|
| 装備を拾ったのに強くならない | 強さの土台はスキルレベルです。装備だけでは上がりません |
| 敵が急に固い／ダメージが通らない | 物理と魔法のどちらが効くか確認してください |
| 少し歩いただけで敵に勝てなくなった | スポーン地点から離れて敵のレベルが上がっています |
| ダンジョンに入れない | 入場条件（戦闘レベルや鍵）が設定されている場所があります |
| エンチャントの効果がいつもと違う | このサーバーではエンチャントの扱いが一部変わっています |

最後の項目が気になったら、次に [バニラとの違い](15-バニラとの違い.md) を読んでください。
「いつもの感覚のままだと損をする所」だけをまとめてあります。
