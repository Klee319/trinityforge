## 2. 解放メカニズム（Model Y：使用ゲート方式）

### 2.1 基本

- **グリフの入手(scribe)は自由**。グリフ自体はいつでも手に入る
- **使用(発動)にスキルツリーperkが必要**。perk未所持グリフは使えない
- ValhallaMMOのperk所持を判定の真実とし、ArsPaper fork側で使用を制御

### 2.2 判定タイミング（α主・β保険の二段構え）

- **(α) 作成時ブロック（主）**: スクライブ/スペルバインド時に、未許可グリフを**スペルに組み込めない**。普段はこれで「なぜ撃てない」を起こさない
- **(β) 発動時不発（保険）**: 既存スペルが後から未許可化（プレステージ等）した場合、cast時に不発＋メッセージで拾う
- 両方 ArsPaper fork にフック

### 2.3 解放維持アイテム（全perk対象）

- 役割: 指定した**任意のperk**（グリフ使用権・クラフト解放・ステ perk 等すべて）を**プレステージ耐性**にする
- プレステージはレベルをリセットするが、本アイテムで保持したperkは維持 → 再育成の負担を軽減
- pon案の「レベル前借りアイテム」は **廃案**（PROGRESSION §5）。プレステージ補助アイテムは**本アイテム（解放維持）の1種のみ**
- 実装: 保持perkを PDC に記録し、プレステージ処理時に再付与／使用ゲート判定で上書き

### 2.4 プレステージとの関係

| 対象 | プレステージ時 |
|---|---|
| スキルレベル | リセット（再育成 = 道を増やす） |
| perk（未保持） | 失効 → 該当グリフ/クラフトが一時使用不可 |
| perk（維持アイテムで保持） | 継続 |
| プレステージ永続ボーナス（各ツリー プレステージⅠ） | 累積付与 |

## 3. 解放タイプと実装ルーティング

スキルツリーの「○○解放」は種類が複数ある。アドオンが種別ごとに振り分ける。

| 解放タイプ | 例 | ルーティング先 |
|---|---|---|
| グリフ使用権 | 光源/破壊/採掘/炸裂/照射… | ArsPaper 使用ゲート（α作成時 + β発動時） |
| クラフトレシピ | 各金属/コア/ソースジェム/Waystone/エンチャ品 | ArsPaper `unlockRecipe()` または Valhalla クラフト解放 |
| 儀式 | 召喚/天候/飛行/修繕(要検討) | ArsPaper `unlockRitual()` |
| 魔法/ポーション | 俊敏跳躍/回復・体力増強/精錬/制作/武器コーティング | ArsPaper（buffグリフ or レシピ） |
| 機能解放 | 司書取引/司祭/鍛冶師/解体/スポナー回収/スケール/スレッド欄拡張 | アドオン内部フラグ／他PL連携 |
| 厳選ドロップ特典 | 遺跡スレッド/海洋スレッド | EliteMobs/loot（ゲートでなく特典） |

## 6. 多経路・矛盾・要検討

- **多経路（意図通り）**: `瞬間移動グリフ` は Ars魔法 A-1-4 と Ars鍛冶 A-4 の両方で解放可能。複数経路は「最適ルートを作らない」原則に合致
- **修繕の扱い（確定：b）**: 「修繕廃止」は**バニラ修繕エンチャのみ**を対象とし、Ars鍛冶 B-2-3 の「**修繕の儀式**」による限定的修繕は**許可**する。
  - 儀式修繕は消耗サイクルへの抜け道になり得るため、コスト（ソース/素材/詠唱手間）を重めにして無限修繕を防ぐ（数値は調整フェーズ）
- **コア/スレッドの正体**: コア類＝上位装備のクラフト/強化材＋コレクション要素、スレッド＝特殊効果系はクラフト・厳選系はトレジャーチェスト（別途 厳選回で詳細）
