## 2. ダメージ計算パイプライン（統一・対称）

与ダメージ・被ダメージを**同一の対称パイプライン**で処理する（攻撃者が敵でも自分でも同じ式）。
1回の攻撃を **物理成分 / 魔法成分** に分解し、各成分を独立に通してから合算する。

### 2.1 成分ごとの処理順

```
（デフォルトダメージ > 0 の成分のみ実行）

1. base   = デフォルトダメージ + 固定追加ダメージ + デフォルトダメージ × 割合追加ダメージ%
2. 会心   : 会心率で判定 → 成立時 base ×= (1 + 会心ダメージ%)
3. 防御率 : base ×= (1 - 防御率% × (1 - 貫通率%))
4. 耐性   : base ×= (1 - 該当耐性%[物理/魔法])          ← 貫通は効かない
5. 補正   : 攻撃側 base ×= ダメージ補正%
            防御側 base ×= (1 - 被ダメージ軽減%)
   preFlat = base（この時点の値を保持）
6. flat   : flat = 守備力[該当type] + 防具強度
            base -= flat
7. クランプ: base = max(base, 1)                        ← 成分ごとに 0以下にしない
8. 固定ダメ: refund = min(固定ダメージ, preFlat - base)   ← flatで削れた分だけ相殺
            base += refund                              ← base は preFlat を超えない

総ダメージ = Σ(物理成分, 魔法成分)
```

### 2.2 デフォルトダメージの定義

| 攻撃源 | デフォルトダメージ |
|---|---|
| 物理（武器・ツール） | **バニラ与ダメージ基準**（attackDamage、mob levelスケール反映） |
| 魔法（触媒・スペル） | **Arsスペル攻撃力(Ars config値) + 触媒の攻撃力ステータス** |

- 攻撃タイプ（物理/魔法）は**攻撃源で確定**: 武器=物理、触媒/スペル=魔法
- ハイブリッド攻撃（物理武器＋魔法エンチャ等）のタイプ判定は未定（§8）

### 2.3 固定ダメージの性質

- `固定ダメージ` は **flat装甲（守備力＋防具強度）を相殺する対重装甲カウンター**
- 最終ダメージは preFlat（flat減算前の値）を超えない
- **flat装甲が無い敵には効果ゼロ**（ペラ装甲特化には無意味）— 意図通りの割り切り

### 2.4 貫通の適用範囲

- `貫通率%` は **`防御率%` のみ無視**する
- `耐性%`・`守備力(flat)` には効かない（三すくみを貫通で崩さないため）

## 3. ステータス一覧（3ファミリー）

### 3.1 共通（武器 / 触媒）— 攻撃ステータス

| ステータス | 実装 |
|---|---|
| 攻撃力 | 武器=バニラattackDamage流用（独自ストックなし）／触媒=新規実装。**Lore表示は共通の「攻撃力」** |
| 貫通率%（防御率を X% 無視） | アドオン |
| 会心率 | 新規実装（物理・魔法 両方） |
| 会心ダメージ | 新規実装（物理・魔法 両方） |
| 追加ダメージ（固定値 / %） | base算出時に加算（会心・防御・貫通・耐性の前） |
| 固定ダメージ | 最終段、flat装甲相殺専用（§2.3） |
| ダメージ補正% | 攻撃側の乗算補正 |
| 耐久力 | 武器=バニラ／触媒=アドオン疑似耐久（§8 M-6 暫定 true） |

### 3.2 共通（装備）— 防御ステータス

| ステータス | 実装 |
|---|---|
| 防御率% | バニラarmor由来の%軽減（貫通対象） |
| 防具強度 | 全体flat減算（バニラarmor toughness流用、固定ダメージcap相殺対象） |
| 被ダメージ軽減% | `ダメージ補正%` の防御側カウンター（type非依存、オーバーエンチャント等） |
| ノックバック耐性 | バニラ流用 |
| 耐久力 | バニラ流用 |

## 4. 命名規約（混同防止）

| 用語 | 意味 |
|---|---|
| 防御率% | vanilla armor由来の%軽減。**貫通の対象** |
| 守備力（物理 / 魔法・flat） | typeごとのflat減算 |
| 防具強度（全体flat） | type非依存のflat減算。固定ダメージcap相殺の対象 |
| ダメージ補正%（攻撃） / 被ダメージ軽減%（防御） | 乗算補正の攻守ペア |

- `守備力` `耐性` は**共通には置かず typed に一本化**（物理=バニラ装備 / 魔法=Ars装備）

## 5. バニラ要素のマッピング

| バニラ要素 | 写像先 | 備考 |
|---|---|---|
| 攻撃力上昇(Strength) / 弱体(Weakness) | デフォルト物理ダメージに内包 | バニラがattackDamageを増減 → そのまま流入 |
| 耐性(Resistance) | **無効化し `防御率%` へ統合** | バニラ独自の最終軽減を残すと二重軽減になるため |
| armor | 防御率% | 使い回し |
| armor toughness | 防具強度 | 使い回し |
| attackDamage | 攻撃力（物理） | 使い回し |
| knockback_resistance | ノックバック耐性 | 使い回し |

---

## 6. バニラ敵の扱い

- **バニラ敵にもデフォルトstatプロファイルを付与**して式を全敵に一貫適用する
  - 耐性0 / 守備力0 / 防御率0 / level = エリア基準
- これによりバニラ/EliteMobsで戦闘感が割れない

---

## 7. 修繕廃止との関係

- 修繕は廃止（DESIGN方針）。よって `耐久力` は**有限の厳選・消耗リソース**として機能する
- 鍛冶/錬金ツリーの耐久回復系（圧縮木材での回復等）が消耗サイクルの調整弁になる
