## 0. 結論

フィールドモブの経路（`mob-types.yml` + `mob-level-table.yml`）は **EliteMobs に一切依存しない**。
レベル刻印は TF 自身の `MobTypeSpawnListener` が `CreatureSpawnEvent` で行い、
討伐報酬は `MobLevelTableListener` がレベル値だけを見て適用する。
一方 `mob-overrides.yml` は `MOB_PROFILE_ID`（EliteMobs フォークだけが書く PDC）で
ゲートされているため、資源サーバでは **一切発火しない**。これは仕様どおりで、
ダンジョン専用の調整が資源ワールドへ漏れないことを意味する。

## 6. 新しいサーバを立てるときの注意

### 6-1. `spigot.yml` の `attribute.maxHealth.max`（必須）

Lv100 時点の最大HPが Spigot の既定上限 1024.00 を超えるモブが **50 種**ある（最大は `WARDEN` の 260819.17）。
既定のままの `spigot.yml` で新サーバを立てると、これらの HP は**無言で 1024.00 にクランプされる**。
症状は「なぜか高レベル帯だけ敵が柔らかい」という形でしか出ないため、既存サーバと同じ値を必ずコピーすること:

```yaml
# spigot.yml
settings:
  attribute:
    maxHealth:
      max: 1.7976931348623157E308
```

### 6-2. 物理防御率が 1.0 を超えるモブ

なし。Lv100 でも全モブが 1.0 未満で、`combat/stat-caps.yml` のクランプに頼っていない。
